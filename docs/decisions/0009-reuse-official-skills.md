# 0009. 공식 스킬·기존 도구 재사용 (중복 구현 금지)

- 상태: Accepted (2026-11-18) — 구현은 「계획」

## 배경
선생님은 PPT·Word·한글 파일도 원한다. 이미 Anthropic의 공식 pptx/docx 스킬이 있는 환경이 있고, HWPX는 `python-hwpx` 같은 기존 라이브러리가 있다. 파일 포맷 처리는 규격이 복잡하고 버전이 바뀌어 직접 만들면 품질·유지 비용이 커진다.

## 결정
- 포맷 자체의 생성·편집(pptx, docx 등)은 **공식 스킬이 있으면 그것에 맡기고**, Teacher Studio는 그 앞뒤의 **한국 교실 고유 가치**만 더한다: 구조(차시·학습 목표·가정통신문 형식), 디자인 방향(큰 글씨·톤), 점검(한글 글꼴 깨짐, 공문 규칙, 학생 정보).
- HWPX는 `python-hwpx`를 쓴다.
- 환경에 공식 스킬이 없으면 지금 방식(웹 슬라이드 → 브라우저 인쇄로 PDF)으로 폴백한다.

## 검토한 대안
- **포맷 라이브러리를 직접 작성**: 시간·버그 부담. 기각.
- **포맷 지원 안 함**: 선생님 수요(공문, PPT 파일)를 외면. 기각.
- **공식 스킬 의존만**: 없는 환경에서 동작 불가. 폴백 유지.

## 결과
- 장점: 중복 제거, 공식 스킬 개선을 자동으로 누림, 저장소는 차별점에 집중.
- 단점: 외부 스킬의 존재·동작에 의존해 환경마다 결과가 다를 수 있다. 어디까지 맡길지 위임 규약을 정해야 한다.
