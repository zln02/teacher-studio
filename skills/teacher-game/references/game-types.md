# 게임 도감 — 고르기·추천·부품 연결

선생님이 종류를 말하지 않으면 **단원 내용 + 교실 상황(칠판/태블릿)** 으로 3개를 추천한다: 「① ○○ (이런 느낌) ② … ③ … 어떤 게 좋으세요? 모르겠으면 ①로 할게요.」

## 연결표
| 방식 | 핵심 동작 | 잘 맞는 내용 | 부품 |
|---|---|---|---|
| 퀴즈쇼·골든벨·OX | 고르기 | 모든 과목, 팀전 | `assets/kits/quiz-show.js` (그대로) |
| 달리는 섬 고르기 | 움직이는 대상 누르기 | 개념 확인, 개인/팀 | `assets/examples/lighthouse-runner.js` 변형 |
| 블록 점프(횡스크롤) | 걸어가서 정답 블록 치기 | 저학년 느낌, 사실 확인 | `assets/examples/block-jump.js` + `packs:["kenney-platformer-core"]` |
| 끌어서 배달·분류 | 끌기 → 칸에 놓기 | 단어 뜻, 분류(생물/무생물), 짝짓기 | 직접 작성: `NG.drag` + `NG.hitTest` |
| 조준·발사 | 끌어서 쏘기 | 과학(빛·힘), 신나는 개인전 | 직접 작성: `NG.drag` onMove로 조준선, onDrop에서 판정 |
| 순서 맞추기·연표 | 차례로 누르기 / 끌어 정렬 | 역사 연표, 실험 순서, 문장 배열 | 직접 작성 |
| 방탈출 | 단계마다 다른 퍼즐 (순서·숫자 다이얼·짝 맞추기·가짜 찾기) | 역사·사회 단원 마무리, 반 전체 협동 | 직접 작성: 단계 장면 `NG.scene("stage")` + 자물쇠 HUD + 위협 게이지 |
| 카드 뒤집기(기억) | 두 장 뒤집어 짝 | 용어-뜻, 그림-이름 | 직접 작성 |
| 보드게임(주사위 칸) | 주사위 → 칸 이동 → 칸 문제 | 단원 총정리, 팀전 | 직접 작성 |
| 꽃길·정원 키우기 (차분) | 고르기/끌기 → 하나씩 자람 | 시 감상, 국어·도덕, 명상 | 직접 작성 + `calm:true` |
| 빈칸 채우기·타자 | 낱말 조각 끌기 | 영어 문장, 국어 문법 | 직접 작성 |
| 지도 찾기 | 지도 위 위치 누르기 | 지리, 역사 지명 | 직접 작성 (SVG 지도 단순화) |

## 방식별 규칙
- **팀 차례제(칠판)**: 한 문제 = 한 팀 차례. 다른 팀이 볼 수 있게 크게. 틀리면 다음 팀에 기회(절반 점수) 선택 가능.
- **반 전체 협동(방탈출)**: 팀 점수 없음. 대신 위협 게이지(적선·시간)로 긴장감. 실패해도 「다시 도전」이 바로 보이게. 단계 사이에 해설 + 선생님이 「다음 문으로」 누름.
- **방탈출 퍼즐 종류**: 순서 누르기(연표) / 숫자 다이얼(연도) / 끌어서 짝 / 가짜 찾기 / 암호 해독(첫 글자 모으기) / 그림 속 숨은 단서. 4단계면 서로 다른 4종을 쓴다. 힌트 버튼은 대가(게이지 +1)를 둔다.
- **개인 태블릿**: 타이머 없거나 넉넉하게, 팀 선택 숨김(`teamChoice:false`), 결과는 별·꽃 개수 같은 세계관 지표로(「점수 ⭐」 대신).
- **끌기 게임**: 탭으로도 답할 수 있게 `onTap`도 연결 (작은 손·전자칠판 펜).
- 문제 표 형식이 안 맞는 퍼즐(순서·짝)은 표를 「단계 | 퍼즐 | 정답 | 함정 | 해설」로 바꿔 보여 준다.
