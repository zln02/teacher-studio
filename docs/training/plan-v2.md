## 오늘 쓰는 비유 (덱·노트·안내서 모두 같은 말)
AI를 모르는 선생님께 회사·앱 이름은 어려워서, 개념을 말할 때는 요리 비유만 써요.

| 진짜 | 비유 (덱 7장 「오늘의 비유 지도」와 같은 말 · deck-e는 7장 앱 화면 짚기 + 8장 주방) |
|---|---|
| AI | 요리사 |
| AI를 만드는 회사 | 식당 (덱에서는 「식당 A·B·C」) |
| AI 앱 | 그 식당의 주방 |
| 하네스 | 레시피 · 밀키트 · 주방도구 · 시식 · 위생 규칙 |
| 내가 하는 부탁(프롬프트) | 주문서 (누구에게 · 어디에 · 어떤 느낌 · 어떤 재료) |
| 앱에 들어 있는 기능 | 그 주방의 레시피 책 · 도구 |
| 일반 채팅창 | 주문만 받는 카운터 (파일은 「주방」 화면에서 만들어요) |

- **실습 장(deck-e 17~18장 · deck-v3 16~17장)만** 실제 앱 이름을 작게 한 번 적어요: 「우리 식당 = Claude 앱」, 주방은 「Cowork」 탭(개인 계정은 「Codex」 앱). 화면을 같이 보며 짚어야 하니까요.
- 식당 A·B·C가 어느 회사인지는 화면에서 말하지 않아요. 발표자용 대응표는 [deck-v2-NOTICE.md](deck-v2-NOTICE.md) 「상표 · 로고」.

오늘의 한 줄: 「바로 만들어 말고, 기획부터 같이 해 줘」

## 가져가실 다섯 단계 (14장 끝 · 20장 미션 판 · 22장과 같은 말 · deck-v3는 13 · 19 · 21장)
1. **주문서 쓰기:** 누구에게 · 어디에 · 어떤 느낌 · 어떤 재료.
2. **기획 같이 하기:** AI가 묻고 내가 고르기. 「바로 만들어 말고, 기획부터 같이 해 줘」.
3. **만들고 한 번 고치기:** 「여기만 고쳐 줘」 한 번 더.
4. **확인하기:** 사실·숫자 / 남의 개인정보(학생·학부모·교직원·가족 등) / 저작권.
5. **공유하기:** 폰으로 보내고 같이 쓰기. 마지막 책임은 여러분께.
