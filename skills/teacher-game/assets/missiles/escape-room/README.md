# 방탈출 (escape-room)

반 전체가 함께 자물쇠 3~6개를 차례로 여는 협동 방탈출. 위쪽 띠에 위기(적 함대·연기·내려오는 천장)가 다가오고, 문이 열릴 때마다 보상 그림(거북선·해독제·신전 문양)이 완성된다. 다 열면 대장면 → 별 3개 결과.

## 언제 쓰나
- 단원 마무리·복습 15~20분, 칠판에 띄우고 모둠이 의논해 대표가 누르기
- 순서 / 숫자 하나 / 짝 / 참·거짓이 섞인 단원 (역사 사건, 과학 개념, 수학 계산)

## 선생님 말 예시
- 「임진왜란 복습을 방탈출로 해 줘. 반 전체가 같이 풀게.」 → joseon
- 「중2 과학 원소 단원, 실험실 탈출 게임 만들어 줘.」 → lab
- 「정수와 유리수 복습, 신전 탈출처럼 문제 5개로.」 → temple + items 5개

## content.json 형식 (fire.py --content, 스킨 위에 덮어씀)
```json
{"title": "제목", "subtitle": "부제 · 자물쇠 {n}개", "teams": 0,
 "world": {"seconds": 420},
 "items": [
  {"kind":"order","q":"차례대로 눌러라!","cards":[{"t":"첫째","d":"힌트용 연도"},"둘째(문자열도 됨)"],"explain":"해설"},
  {"kind":"dial","q":"숫자를 맞춰라","clue":"단서 (\n 줄바꿈)","answer":"1592","hint":"15","explain":"해설"},
  {"kind":"match","q":"짝지어라!","pairs":[{"who":"끌 카드","what":"설명"}],"explain":"해설"},
  {"kind":"fake","q":"가짜를 찾아라!","lines":["참1","참2","참3"],"fake":"거짓 한 줄","explain":"해설"}]}
```
- items 3~6개(7개부터 잘림), kind는 order·dial·match·fake. cards는 **정답 순서대로** 적는다(화면에서 섞임).
- order 카드 2~6장(홀수면 마지막 카드 가운데). `d`가 있으면 힌트 때 보임, 없으면 힌트가 다음 카드를 찍어 줌.
- dial `answer` 1~6자리 숫자. 앞에 `-`/`+`를 붙이면 부호 다이얼이 생김(예 `"-18"`). `hint`는 앞자리부터 맞춰 줄 글자.
- match 2~5쌍(4쌍까지 권장, 5쌍이면 카드 높이 98px). fake 참 2~5줄 + 거짓 1줄.
- world에서 선생님이 자주 바꾸는 키: `seconds`(게이지가 0이 되는 초, 기본 480), `lockName`(문/잠금/봉인), `rules`(시작 화면 3줄, `{n}`=자물쇠 수),
  `threatLabel`·`threatDanger`(게이지 글), `startBtn`·`nextBtn`·`finaleBtn`, `finaleBanner`·`finaleWin`, `resultTitle`·`resultPerfect`·`resultLine`,
  `loseTitle`·`loseMsg`, `clueTitle`·`dialBtn`, `hintBtn`·`hintFloat`·`wrongMsg`·`costFmt`(`{h}`=힌트 비용 8, `{p}`=오답 비용 10).
- 제목·부제·규칙의 `{n}`은 실제 문제 수로 바뀜. `calm:true`면 흔들림·번쩍임 꺼짐.

## 스킨
- **joseon** 조선 수군 작전실: 밤바다로 적 함대가 다가오고 포구의 거북선이 6조각으로 완성 → 노을 바다로 출항해 적선 격파. 안내: 전립 쓴 수군 장교.
- **lab** 폭주하는 실험실: 연기 구름이 왼쪽에서 번지고 경광등이 깜빡, 삼각 플라스크에 해독제가 눈금만큼 차오름 → 플라스크 분사로 연기 제거. 안내: 고글 쓴 실험복 연구원. (중2 물질의 구성 4문제)
- **temple** 고대 신전: 가시 박힌 돌천장이 내려오고 모래시계가 줄어듦, 문 위 태양 문양이 문제 수만큼 조각으로 빛남 → 돌문이 갈라지며 빛과 보물. 안내: 탐험모·횃불 든 탐험가. (중1 정수와 유리수 4문제)

## 크기·사용 환경
- 1920×1080 무대(엔진이 화면에 맞춤). 문제 60px, 카드 46~52px, 버튼 높이 110px+(fake 6줄·match 5쌍일 때만 86~98px).
- 칠판 반 전체 협동이 기본(teams 0). teams 2~6이면 문제마다 차례 팀이 돌아가고 연 팀이 100점, 결과에 팀 점수 표시.
- 태블릿 개인도 동작(teamChoice:false). 세로 태블릿은 위아래 여백.
- 선생님 메뉴 ⚙: 「정답 보기」= 지금 자물쇠 열기, 「다음으로」= 풀기 전엔 정답 보기 / 해설 화면에선 다음 문. Space도 다음.
- 게이지 0% → 「이 문부터 다시」(게이지 55%) / 「처음부터」.

## 확인된 것 (2026-11-18)
- fire.py 3스킨 모두 PASS(0 fail, 0 warn), 각 151KB 안팎.
- Playwright 1280×720으로 3스킨 끝까지: 오답(순서·다이얼·끌기 짝), 끌기+탭 짝짓기, 힌트, ⚙ 정답 보기·다음으로, 대장면, 결과, 다시 하기, 게이지 0 → 실패 화면 → 이 문부터 다시. 페이지 오류 0.
- 6문제(order 6장·3장, dial 5자리·부호+5자리, match 5쌍, fake 6줄) + 3팀, 3문제 + 2팀 콘텐츠도 끝까지 확인.
