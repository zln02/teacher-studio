AI에게 무기를 주면

오늘의 한 줄

「바로 만들어」 말고, 「기획부터 같이 해 줘」

 

1. 하네스란?

하네스 = AI에게 도구와 레시피를 주는 것 (김치볶음밥도 레시피가 있으면 실패하지 않아요)

2. 실습 4단계

① AI 열기 · Claude 앱 (미리 준비됨)

② 「컴퓨터를 쓰는 모드」 고르기 · Claude 데스크톱: Cowork 또는 Code 탭 / ChatGPT 개인: Codex 앱

③ 링크 붙여넣고 한 줄 · github.com/zln02/teacher-studio + 「내가 준 링크에 하네스 세팅해 줘」

④ 만들고 싶은 것 말하기 · 예시 (그대로 따라 말해도 돼요)

따라 말하기

※ 「나는 중학교 선생님인데 오늘 수업에 쓸 AI 코딩 도우미 만들어 줘. 나한테 물어보지 말고 네가 알아서 만들어.」

3. 막히면 (Plan B)

가. github.com/zln02/teacher-studio 의 dist 폴더에서 zip 파일 받기

나. Claude 「Customize → Skills」에 zip 올리기

다. 코드 실행 켜기 · Settings → Capabilities

4. 꿀팁 3줄

가. 그냥 시키지 않기 · 도구와 길을 같이 주기

나. 한 번 제대로 말하기 · 누구에게 · 어디에 · 어떤 느낌 · 어떤 재료

다. 끝나면 확인 · 사실 · 숫자 · 출처는 원문으로, 학생 정보는 넣지 않기

5. 이렇게 써 보세요

만들 것

이렇게 말해 보세요

게임

「중2 과학 「빛의 반사」 복습 퀴즈 게임 만들어 줘. TV로 띄워서 모둠 대항으로.」

슬라이드 · PPT

「학부모 설명회 10분 발표 자료 만들어 줘. 차분하고 믿음직한 느낌으로.」

가정통신문 (한글)

「현장체험학습 안내 가정통신문을 한글 파일로. 회신서도 붙여 줘.」

수업 도구

「발표 순서 뽑기 + 3분 타이머. 교실 TV에서 크게 보이게.」

성적 분석 보고서

「이 엑셀로 반별 평균 비교 보고서 만들어 줘. 학생 이름은 빼고.」

프로그램

「모둠 활동 점수판 프로그램 만들어 줘. 인터넷 없이 열리게.」
