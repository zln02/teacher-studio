# 🗣 이렇게 말해 보세요 — 선생님 주문 모음

평소 말투 그대로 괜찮아요. 실제로 만든 결과는 [examples.md](examples.md)에서 볼 수 있어요. **누가(학년) · 무엇을(단원) · 어디서(칠판/태블릿) · 어떤 느낌** 중 생각나는 것만 말하면, 빠진 건 AI가 보기를 붙여 물어봐요.

## 🎮 수업 게임
| 이렇게 말하면 | 이렇게 나와요 |
|---|---|
| 「중2 과학 빛과 파동 방탈출, 칠판에 띄워서 반 전체가 풀 거야. 긴장감 있게」 | 방탈출 · 실험실 디자인 · 4단계 · 위기 게이지 |
| 「중1 영어 단어 12개로 모둠 게임. apple 사과, library 도서관 …」 | 끌어서 보내기 · 우체국 · 4팀 · 발음 듣기 |
| 「독도 퀴즈 10문제 종 울리기처럼」 | 퀴즈쇼 · 강당 종 울리기 |
| 「순물질이랑 혼합물 나누는 거, 애들 패드로 각자」 | 끌어서 보내기 · 분리수거 로봇 · 개인 |
| 「이 학습지(PDF)로 게임 만들어 줘」 | 학습지 내용에서만 문제를 뽑아 표로 확인 → 게임 |
| 「수업 시작 5분 동안 할 퀴즈」 | 문제 5~6개, 짧은 한 판 |

## 🖥 수업 슬라이드
| 이렇게 말하면 | 이렇게 나와요 |
|---|---|
| 「광합성 수업 슬라이드 10장, 칠판 느낌으로」 | 칠판 디자인 · 질문·개념 카드·단계·퀴즈 공개 |
| 「학부모 설명회 자료 8장, 따뜻하게」 | 파스텔 노트 디자인 |
| 「선생님들 연수 자료, 깔끔하고 세련되게」 | 키노트형 디자인 |
| 「인쇄도 할 거야」 | 크롬 인쇄 → PDF 안내 (한 장에 한 슬라이드) |

## ✨ 영상·화면
| 이렇게 말하면 | 이렇게 나와요 |
|---|---|
| 「과학 과목 소개 영상, 첫 시간에 틀 거야」 | 과목 소개 · 과학 네온 · 35~45초 |
| 「국어 과목 소개, 전통 느낌으로」 | 과목 소개 · 붓글씨 |
| 「영어 시간 시작할 때 뉴스처럼」 | 과목 소개 · 영어 뉴스 |
| 「수업 시작할 때 띄울 화면, 오늘 주제는 ○○」 | 수업 시작 화면 · 카운트다운 |
| 「이거 영상 파일로 줘」 | MP4 (도구가 있으면) / 🎥 버튼 녹화 안내 |

## 🎨 느낌 바꾸기 (만든 뒤에)
| 이렇게 말하면 | 이렇게 바뀌어요 |
|---|---|
| 「더 화려하게」「밋밋해」 | 정답·마무리 연출 강화, 반짝이·폭죽 |
| 「너무 정신없어」「눈 아파」 | 효과 줄이기, 차분 모드 |
| 「글씨가 뒤에서 안 보여」 | 글자 1.3배, 대비 강화 |
| 「우리 학교 색으로」 | 학교 색 물어보고 색 변경 |
| 「이 사진 느낌으로」(사진 첨부) | 색·글씨·배치·속도를 뽑아 그 느낌으로 |
| 「아까가 나았어」 | 직전 버전으로 되돌리기 |

| 이렇게 말하면 | 안내 |
|---|---|
