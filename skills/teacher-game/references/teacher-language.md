# 선생님 말 사전 — 선생님 말을 작업으로, 작업을 선생님 말로

선생님은 개발 용어를 모른다. 아래 표로 **선생님 말 → 해야 할 작업**을 바로 바꾸고, 대답할 때는 **개발 용어 → 선생님 말**로 바꿔 말한다.
표에 없는 말도 같은 원리로 해석한다: 「수업 장면에서 무엇이 불편한가?」를 먼저 떠올리고, 가장 그럴듯한 해석으로 **바로 고친 뒤** 「○○로 이해하고 이렇게 바꿨어요」라고 한 줄로 알린다. 해석이 둘 이상으로 크게 갈릴 때만 짧게 되묻는다(보기 2~3개).

## 1. 만들기 요청
| 선생님 말 | 해석 → 작업 |
|---|---|
| 「애들이랑 할 거 하나 만들어 줘」「재밌는 거」 | 게임 요청. 단원·학년만 묻고 게임 종류는 3개 추천 |
| 「칠판에 띄울 거야」「TV로 같이 할 거야」 | 전자칠판 반 전체용: 모둠 대결 기본, 큰 글씨, 선생님 메뉴 |
| 「애들 패드로」「각자 폰으로」 | 태블릿 개인용: 혼자 모드 기본, 터치 영역 크게, 세로 화면도 깨지지 않게 |
| 「모둠별로」「조별로」「반 나눠서」 | 팀 대결(팀 수 물어보기, 기본 4) |
| 「1등 정해 주는 거」「점수 내기」 | 팀 점수판 + 결과 화면 시상. 개인 실명 순위는 만들지 않음 |
| 「복습용」「쪽지 시험 대신」 | 형성평가형: 해설 필수, 틀린 문제 다시 풀기 |
| 「수업 시작할 때 5분」 | 짧게: 문제 5~6개, 한 판 5분 이내 |
| 「이 학습지로」「이거 보고」(파일 첨부) | 첨부 내용에서만 문제 출제. 한글(HWP)이면 「PDF로 저장해서 올려 주세요」 안내 |
| 「교과서 ○쪽」 | 교과서 원문이 없으므로 내용을 붙여 달라고 요청하거나, 일반 지식으로 만들고 「확인 필요」 표시 |
| 「작년에 만든 거처럼」 | 이전 결과물 파일을 올려 달라고 요청 → 형식 그대로 내용만 교체 |

## 2. 고치기 요청 (가장 많이 쓰임)
| 선생님 말 | 해석 → 작업 |
|---|---|
| 「더 화려하게」「밋밋해」「심심해」 | 정답 연출 강화(반짝이 수↑·폭죽·화면 번쩍), 배경 움직임 추가, 콤보 연출, 배경음악 켜기 |
| 「너무 정신없어」「눈 아파」 | 효과 줄이기: 흔들림·반짝이 축소, 배경 정지, 색 대비 낮춤 |
| 「글씨가 안 보여」「뒤에서 안 보여」 | 글자 크기 1.3배, 대비 강화, 문장 짧게 줄바꿈 |
| 「애들이 헷갈려해」 | 화면 단순화: 보기 수 줄이기, 버튼 크게, 첫 판에 따라 하기 안내 추가 |
| 「너무 어려워」/「너무 쉬워」 | 문제 난이도 조정 + 제한 시간 ±10초 + 힌트 추가/제거 |
| 「너무 빨라」「시간이 모자라」 | 제한 시간 늘리기(+10초), 움직이는 게임은 속도 70% |
| 「소리가 시끄러워」「소리 안 나」 | 효과음 볼륨↓·배경음악 끄기 / 「화면을 한 번 누르면 소리가 나요(브라우저 규칙)」 안내 + 소리 버튼 확인 |
| 「안 눌려」「터치가 안 돼」 | 누르는 영역 키우기, 움직이는 대상은 「누르는 순간」 판정으로 변경 |
| 「화면이 잘려」「꽉 안 차」 | 화면 맞춤 점검, 전체 화면 버튼 안내(F11) |
| 「멈췄어」「안 넘어가」 | 진행 버튼·다음 문제 흐름 점검, 선생님 메뉴 「다음으로」 안내 |
| 「색깔 바꿔 줘」「우리 학교 색으로」 | 테마 색 변경(학교 색 물어보기) |
| 「캐릭터 귀엽게」「동물로」 | SVG 캐릭터 교체 또는 에셋 팩 캐릭터 |
| 「틀린 거 다시 풀게」 | 「틀린 문제만 다시」 버튼 확인/추가 |
| 「문제 바꿔 줘」「3번 정답 틀렸어」 | 해당 문제만 수정, 나머지 그대로 |
| 「처음 거로 돌려 줘」「아까가 나았어」 | 직전 버전으로 되돌리기 |
| 「제목 바꿔」 | 제목만 수정 |
| 「다른 게임으로 바꿔 줘」 | 같은 문제로 다른 방식(도감에서 3개 제안) |

## 3. 나누기·보관 요청
| 선생님 말 | 해석 → 안내 |
|---|---|
| 「애들한테 보내고 싶어」「링크로」 | 오른쪽 위 「게시(Publish)」 → 링크 복사 (학생은 로그인 없이 가능) |
| 「QR로」 | 크롬 주소창 공유 버튼 → 「QR 코드 만들기」 |
| 「저장하고 싶어」「USB에 넣을래」 | 「다운로드」로 파일 받기 → 인터넷 없이도 크롬에서 열림 |
| 「다른 선생님한테 주고 싶어」 | 게시 링크 공유, 또는 파일 전달(받은 선생님도 Claude에 올려 고칠 수 있음) |
| 「홈페이지에 올릴래」 | 학교 게임 모음 올리기 안내(링크 붙여넣기) |
| 「한글 파일로」 | 한글 문서 요청 → HWPX 또는 DOCX로 만들고 한컴독스(웹)에서 열기 안내 |
| 「인쇄할래」 | 인쇄용(A4) 버전 따로 만들기 |

## 4. 막혔을 때 선생님 말
| 선생님 말 | 확인 순서 |
|---|---|
| 「아무것도 안 떠」 | ① 오른쪽 결과물 창 열렸는지 ② 「다시 띄워 줘」로 재생성 ③ 크롬 최신인지 |
| 「이상한 글자가 떠」「영어로 뭐가 나와」 | 오류 화면 → 「캡처해서 붙여 주세요」, 캡처를 보고 고침. 오류 문장을 선생님께 그대로 설명하지 않음 |
| 「저장소? 그런 거 몰라」 | 설정·저장소 이야기는 꺼내지 말고 결과물만 다룬다 |
| 「사용량 다 썼대」 | 무료 사용량 안내: 몇 시간 뒤 다시 가능, 그동안 받은 파일은 그대로 사용 가능 |

## 5. 대답할 때 바꿔 말하기 (금지어 → 선생님 말)
| 쓰지 말 것 | 이렇게 말하기 |
|---|---|
| HTML, 코드, 스크립트, 파일 구조 | 게임 파일, 게임 |
| 아티팩트, 렌더링 | 오른쪽에 뜬 화면, 결과물 화면 |
| 배포, 퍼블리시, 호스팅 | 공유 링크 만들기 |
| 버그, 에러, 예외 | 이상한 부분, 안 되는 부분 |
| 브라우저 | 인터넷 창(크롬) |
| 캐시 | 예전 화면이 남아 있는 것 → 「새로고침(F5)」 |
| 레이아웃, UI, UX | 화면 배치, 버튼과 글자 |
| 애니메이션, 이펙트, 파티클 | 움직임, 반짝이 효과 |
| 폰트 | 글씨체 |
| 반응형, 해상도 | 화면 크기에 맞추기 |
| 로컬 스토리지 | 이 기기에만 기록 |
| 라이브러리, CDN, 패키지 | (말하지 않음) |
| 리포지토리, 클론, 깃허브 | (말하지 않음 — 「스튜디오 불러오기」) |
| 프롬프트 | 요청 문장, 주문 |
| 스킬 | 미리 가르쳐 둔 레시피 |
| 토큰, 컨텍스트 | 사용량, 대화가 길어짐 |

## 6. 대답 형식
- 짧게: 무엇을 바꿨는지 1~3줄 + 다음에 해 볼 만한 고치기 2개
- 선생님이 해야 할 행동은 **누를 버튼 이름 그대로** 쓴다 (「오른쪽 위 '게시' 버튼」)
- 질문은 보기 붙여서: 「몇 모둠으로 할까요? (2 / 3 / 4)」
- 「~할 수 없습니다」로 끝내지 않는다. 안 되는 이유를 한 줄로 말하고 **바로 대안**을 준다
