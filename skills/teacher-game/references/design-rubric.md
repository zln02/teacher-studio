# 디자인 점검표 (만든 뒤 보여 주기 전에 반드시)

순서: **만들기 → 점검(check) → 디자인 점검(`design_review.py`) → 위 PNG(접촉 시트)를 직접 눈으로 보기 → 이 표대로 고치기 → 다시 만들기 (최대 2번)**

```
python3 scripts/design_review.py game.html --out review/
```
`review/<이름>-sheet.png`(제목·문제·정답·오답·결과·배경만 6칸)를 **그림으로 열어서** 아래를 하나씩 확인해요. 숫자(`-metrics.json`)는 보조예요. 눈으로 본 판단이 우선이에요.
**기준은 옛 스킨이 아니라 요즘 상용 서비스(앱·게임·방송 그래픽)의 완성도예요.** 옛 스킨 수치(`assets/design-baseline.json`)는 「이 밑으로는 안 된다」는 최소선일 뿐이에요.

## 요즘 상용 디자인의 모습 (눈으로 보는 10가지)
| 질문 | 아니오일 때 고치는 법 (spec) |
|---|---|
| 1. **한눈에 위계가 보이나요?** 제일 먼저 문제/제목, 다음이 보기, 마지막이 장식 순서로 읽히나요 | 문제 글 줄이기, `design.style`을 차분한 쪽(minimal-premium·glass-3d)으로 |
| 2. **여백에 목적이 있나요?** 빈 곳이 「쉼」인지 「휑함」인지. 장식은 가장자리·바닥·배경에 모이고 글자 둘레는 비어 있나요 | `design.seed`/`design.layout` 바꾸기, 장면이 있는 style로 |
| 3. **시각 언어가 하나인가요?** 버튼·카드·점수판·제목이 같은 스타일(각진/둥근, 외곽선/그림자)을 쓰나요 | `design.style` 하나를 정하고 `choice/card/score/title_style`을 따로 섞지 않기 |
| 4. **장면(세계)이 있나요?** 우주·바다·역사처럼 어디인지, 소품·도우미가 주제에 맞나요 (도우미가 없어도 괜찮아요) | `design.words`에 주제 낱말 넣기 |
| 5. **이 요청만의 한 요소가 있나요?** 독도의 섬, 송년회의 시계처럼 내용에서 나온 그림 | 제목·단원 낱말을 구체적으로, 필요하면 `custom_svg` |
| 6. **글이 편하게 읽히나요?** 카드 안·제목·버튼, 장식에 묻히지 않나요 | 대비 숫자 2 미만이면 필수 수정 |
| 7. **서로 겹치는 것이 없나요?** 캐릭터·말풍선·글자 상자 | 보기 줄이기, 글 줄이기 |
| 8. **색이 한 세트로 어울리나요?** 포인트 색이 1~2개로 정리됐나요 | `design.style` 바꾸기 |
| 9. **움직임이 다듬어졌나요?** 정답·오답·전환에 반응이 있고, 과하지 않고 같은 박자인가요 | `calm` 분위기 / `transition`은 style이 정해요 |
| 10. **다른 게임과 닮지 않았나요?** 같은 학교·같은 선생님의 다른 게임과 배치가 같지 않나요 | `design.seed`를 바꾸면 배치·스타일이 새로 뽑혀요 (자동 점검이 닮음을 알려 줘요) |

## 자동으로 잡아 주는 것 (design_review.py)
- **소품 관련성**: 자동 테마 소품마다 태그(바다·우주·역사 …)가 있고 세계의 태그와 맞아야 해요.
- **밋밋한 카드**: 기호(?)만 있는 흰 카드가 3장 이상이면 WARN.
- **배치 닮음(sameness)**: 같은 방식의 다른 결과와 배치 지문이 86% 이상 같으면 WARN → 「다른 배치로 다시」.
- **숫자**: `deco_density` 장식 밀도 · `empty_ratio` 휑함 · `colors` 색 가짓수는 최소선 아래일 때만 WARN (미니멀 스타일은 여백이 디자인이라 제외). `hierarchy` 1.25 미만, `min_contrast` 2 미만 FAIL·4.5 미만 WARN, `overlaps` 0.
WARN이 나와도 눈으로 보아 괜찮고 이유가 있으면 그대로 두어도 돼요. FAIL은 고쳐요.

## 한 번 고칠 때의 순서
1. 가장 큰 문제 하나만 고른다.
2. spec의 `design.words` / `style` / `seed` / `layout`만 바꾼다 (문제·정답은 그대로). 더 개성이 필요하면 `custom_css` · `custom_svg`.
3. 다시 `build.py` → `design_review.py` → 그림 보기. 2번을 넘기면 지금 모양으로 보여 주고 「이 부분은 이렇게 했어요」라고 알린다.
