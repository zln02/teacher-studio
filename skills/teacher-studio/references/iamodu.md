# 아이모두 route (전남 teachers) · 2026-11-20 확인

When to read: the user is a 전남 teacher, or mentions 아이모두 / ai.jne.kr / JneGPT / AIEP / 전남(광주)교육청, or names a tool below.
What to do: build your own result as usual, then add **one line** naming the 아이모두 tool that also does it (or that keeps student data inside the school platform). Never replace your result with the link; never send them away without an answer.

Line pattern (Korean): 「아이모두에 있는 <도구>로도 할 수 있어요: [도구모음] → <도구>. <one reason>.」

## Facts the line may rely on
- 아이모두 = 교육청 AI 교수학습 플랫폼, `https://ai.jne.kr`, 교원(교직원) login. Home [도구모음] shows 12 tools per page, ▶ for the next page. 45 tools + 「수업도구 ToolKit」 (the character at the home bottom-right).
- Most tools open in a new tab without a second login. Google tools ask 「본인 인증 → 계속」 once. Publisher and some edtech tools need a one-time account link (the teacher does it).
- [도구 설정] turns tools on/off; [수업도구 추가] adds any site (no auto-login then).

## Privacy rule (always)
If the request carries real student data (names, scores, 상담, 생기부, 명단, 사진), say in one line that it should stay inside the school platform (클래스룸·스프레드시트·유레카·해당 학습 도구) and do your part with blanks or fake data. JneGPT and all tools show 「개인정보 등 민감정보는 입력·업로드하지 마세요」 too. Legal questions -> `teacher-law`.

## Do not
- Do not claim features not listed here; inner screens of 소개만 tools (출판사 8, 띵커벨, 플랭스쿨, 카피킬러, 심스페이스) were not checked.
- Do not mention 아이모두 to users outside 전남 unless they bring it up.
- Names change: if the user's screen differs, trust the user's screen.
