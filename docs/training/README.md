# (예전 자료) 교사 연수 자료: AI를 진짜 잘 쓰는 사람들은 이렇게 써요 (60분 · 실습형)

대상: 업무에 AI를 써 보려는 초·중·고 선생님 (AI를 처음 쓰는 분 포함).
핵심 메시지: **AI는 이미 잘해요. 무기(도구·재료)를 안 쥐여 줘서 중간에 지치는 거예요. 재료와 도구를 쥐여 주면 달라져요.**
성격: 돈 받는 것 없는 무료 공개 도구(재능기부)를 나누는 실습형 연수. 홍보가 아니에요.
비유: 주 비유는 **빈 주방의 실력 좋은 요리사** (→ 레시피·손질된 재료·좋은 도구·시식을 갖춰 주기). 하네스 부분에서만 「옷·선글라스·오토바이·차, 내비게이션, 안전벨트」를 짧게 덧붙여요.

## 연수 목표 3가지
1. AI가 왜 헤매는지 이해한다 (맨몸 AI vs 도구를 쥔 AI)
2. AI에게 재료와 도구를 쥐여 주는 법을 익힌다
3. 직접 설치하고 내 업무에 바로 써 본다

## 구성 (60분)
| 시간 | 내용 |
|---|---|
| 0–5 | 오프닝: 「제가 배우고 연구하고 익혀 온 것」 + 연수 목표 3가지 |
| 5–15 | 맨몸 모델 vs 무기를 쥔 모델(하네스), 여섯 가지 말(모델·프롬프트·하네스·스킬·도구·환각, 요리로 치면), AI 회사들의 도구 경쟁, 재능기부 선물 |
| 15–25 | 두 화면 시연: 왼쪽 깡통 vs 오른쪽 하네스, 재료를 주면 깡통도 좋아져요 |
| 25–35 | 같이 설치 (Claude 앱, zip 올리기, 모둠 대표가 공용 PC에서) |
| 35–55 | 마음껏 만들기 (만들고 싶은 거 아무거나, 우수 결과 큰 화면 공유) |
| 55–60 | 마무리 + QR + GitHub + 포켓 카드 |

## 이 연수의 약속
- 훈계하지 않아요. 따뜻하게, 같이 해 봐요 (학생 이름·사진은 가명으로, 한 줄만 가볍게).
- 측정하지 않은 숫자는 말하지 않고, 없는 기능을 되는 것처럼 보이지 않아요.
- 도구가 이기지 못한 부분도 그대로 보여 줘요. 맞지 않는 요청은 하네스가 비켜서요.
- 돈 받는 것 없는 무료 공개 도구이고, 홍보가 아니에요.
