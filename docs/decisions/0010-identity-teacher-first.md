# 0010. 정체성: 선생님 맞춤이 기본, 용도 제한은 없다

- 상태: Accepted (2026-11-18)

## 배경
도구의 첫 사용자는 코딩을 모르는 교사다. 하지만 같은 교사가 가족 영상, 결혼식 축사 슬라이드, 동호회 퀴즈를 부탁하기도 한다. 「교사용」으로 묶어 거절하면 쓸모가 줄고, 용도를 안 가리면 교실 기본값(큰 글씨, 학생 정보 금지)이 흐려진다.

## 결정
- **선생님 맞춤이 기본값이고, 사용은 누구에게나 열려 있다.** 교실 기본값은 ON: 칠판용 큰 글씨, 태블릿 터치, 학생 정보 칸 없음, 선생님 말 알아듣기(개발 용어 금지, `teacher-language.md`).
- 수업이 아닌 요청은 **거절하거나 수업 얘기로 돌리지 않고** 같은 도구로 만들되 **기본값만 조정**한다: 학년·교과·「수업 목표」 대신 용도·분위기·보는 사람, 글자 크기는 보는 화면에 맞춤(spec의 `use: "personal"`, ADR 0003).
- 학생 정보 금지·사실 확인·저작권 안내 같은 **절대 규칙은 용도와 무관하게 유지**한다.
- 종류는 고정 목록이 아니다. 지금 없는 것(문서·한글 파일, PPT 파일, 영상 편집)은 「준비 중」이라고 정직하게 말한다.

## 검토한 대안
- **교사 전용**: 단순하지만 수요를 잘라 낸다. 기각.
- **범용 도구(기본값 없음)**: 교실 품질 기준이 흐려지고 첫 사용자가 헤맨다. 기각.
- **용도별 별도 제품**: 유지 비용 증가. 기각.

## 결과
- 장점: 정체성이 한 문장으로 설명되고(「선생님 맞춤이 기본, 누구나 쓸 수 있어요」), 교실 사용자는 기본값 덕에 질문 없이 좋은 결과를 얻는다.
- 단점: 교실 가정이 깊이 박혀 있어 개인 용도에는 일부 문구·메뉴가 어색할 수 있다. 「준비 중」 범위가 넓어 기대와 현재 기능 사이에 간극이 있다.
