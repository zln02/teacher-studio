# 메뉴판 (모둠 책상용 · A4 한 장)

**오늘 진짜 필요한 것 하나, 아무거나 — 일상이든 업무든 수업이든.** 처음엔 내 일상 것부터 해 봐도 돼요.
남의 개인정보(학생·학부모·교직원·가족 등 이름·사진·성적·연락처)는 넣지 않아요.

다섯 단계 (deck-v3 19장 미션 판 · 21장과 같은 말 · deck-e 18장은 네 단계: Cowork · Codex 열기 → 한 줄로 부탁 → 양식 · 예시 붙이기 → 받아서 확인)
① 주문서 쓰기 (누구에게·어디에·어떤 느낌·어떤 재료) → ② 기획 같이 하기 (AI가 묻고 내가 고르기) → ③ 만들고 한 번 고치기 → ④ 확인하기 (사실·숫자 / 남의 개인정보 / 저작권) → ⑤ 공유하기
만들기는 보통 2~4분, 기획 질문에 답하는 시간까지 5~8분이에요. 기다리는 동안 주문서를 다듬어요.

예시일 뿐이에요 (세 칸 모두 같아요)

| 일상 | 업무 | 수업 |
|---|---|---|
| 가족 여행 일정표 | 안내문·공문 | 게임 |
| 모임·동호회 안내문 | 회의·보고 자료 | 수업 도구 (타이머·뽑기·점수판) |
| 가계부·지출 정리 | 엑셀 → 한눈에 보는 보고서 | |
| 아이와 할 퀴즈 게임 | | |

말해 보기: 「다음 달 가족 여행 2박 3일 일정표, 기획부터 같이 해 줘」 · 「체험학습 안내문 기획부터 같이 해 줘」 · 「모둠 활동 10분 타이머랑 발표 순서 뽑기 기획부터 같이 해 줘」
🎬 영상은 오래 걸려요. 시간이 남을 때 해요.

## 주문서 한 줄 틀
「[누구에게] [어디에 쓸 건데] [어떤 느낌으로] [이 자료로] [무엇을] 만들어 줘」
예: 「5학년 · 수업 시작 5분 · 신나게 · 첨부한 학습지로 · 태양계 퀴즈 5개」

## 만든 뒤에
- 시식: 내용이 맞는지 눈으로 확인 (사실·숫자·출처)
- 간 맞추기: 「더 크게」「더 따뜻하게」「3번만 고쳐 줘」
- 공개 전: 남의 그림·글·음악이 있으면 확인
