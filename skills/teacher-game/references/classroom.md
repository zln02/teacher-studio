# 교실 운영 규칙 (전자칠판·태블릿)

## 글자·버튼 크기 (1920×1080 무대 기준)
| 대상 | 칠판(반 전체) | 태블릿(개인) |
|---|---|---|
| 문제 문장 | 60px 이상 | 48px 이상 |
| 보기·정답 버튼 글자 | 48px 이상 | 40px 이상 |
| 답하는 버튼·끌 대상 | 높이 110px 이상 | 높이 96px 이상 |
| 보조 글(해설·안내·카드 설명) | 34px 이상 | 30px 이상 |
- 예외: 선생님 메뉴·소리·전체 화면 아이콘(88px), 팀 선택 작은 버튼은 그대로 둔다.
- 대비: 밝은 배경엔 진한 글자, 어두운 배경엔 흰 글자 + 그림자. 반투명 카드 위 글자 금지.
- 정답/오답은 색 + 기호(✔/✖) + 소리 세 가지로.

## 칠판 팀전
- 기본 4팀(동물 이름), 문제당 20~30초, 4문제마다 보너스(역전).
- 차례 팀 이름을 크게 화면 위쪽에. 「모둠끼리 의논 → 대표가 누르기」 안내 한 줄.
- 오답 망신 금지: 「아쉬워요」 수준, 팀 이름과 오답을 크게 같이 띄우지 않음.

## 태블릿 개인
- 시작 화면에 「가로로 돌려 주세요」 한 줄 (세로면 화면이 작아짐).
- 소리는 선생님이 끄기 쉽게 기본 볼륨 낮게. 교실 30대가 동시에 울린다.
- 혼자 끝까지 갈 수 있게: 타이머 없음 기본, 다시 하기·틀린 문제만 버튼.
- 결과 화면을 선생님이 둘러보며 볼 수 있게 크게(별·꽃·불빛 개수).

## 공통
- 첫 문제 전 「따라 하기」 한 장면(손가락 그림 + 한 줄) — 「애들이 헷갈려해」 예방.
- 한 판 5~10분. 문제 10개 기본, 「수업 시작 5분」이면 5~6개.
- 학생 이름 입력·기록 저장·실명 순위 금지.
