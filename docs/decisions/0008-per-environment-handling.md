# 0008. 환경별 처리 (Claude 앱 / Claude Code / Codex)

- 상태: Accepted (2026-11-18)

## 배경
같은 선생님이 Claude 앱(클라우드 샌드박스, 인터넷 제한), Claude Code(내 컴퓨터), Codex(승인 창, 기본 인터넷 꺼짐) 중 어디서든 쓴다. 환경마다 되는 것이 다르다(영상 MP4, 최신 법 검색, 파일 저장, 공유 링크).

## 결정
- **스킬 묶음은 하나**(Agent Skills 표준, `SKILL.md`)로 유지하고 환경별 분기는 별도 코드가 아니라 **감지 + 폴백**으로 처리한다.
- `studio.py doctor --agent <claude-app|claude-code|codex>`가 환경을 확인해 `~/.teacher-studio/env.json`에 저장하고, 준비 카드에 「이 환경에서 되는 것」을 보여 준다.
- 안 되면 **우아하게 물러난다**: MP4 불가 → 화면의 🎥 버튼으로 webm 녹화, 점검용 브라우저 없음 → 정적 검사만(ADR 0004), 웹 검색 없음 → 공식 링크만(ADR 0005).
- 큰 도구는 **처음 필요할 때 동의를 받고 설치**한다(ffmpeg 약 150MB 등). 설치하지 않아도 핵심 기능은 동작한다.
- Claude 앱 업로드를 위해 스킬 `description`을 **200자 이하**로 유지하고, 스킬별 zip 5개를 `dist/`에 만든다.

## 검토한 대안
- **환경별 별도 스킬 세트**: 유지 비용 2~3배, 불일치 발생. 기각.
- **모든 도구를 미리 설치**: 무겁고 샌드박스에서 불가능. 기각.
- **환경 감지 없이 실패 후 안내**: 선생님이 오류를 먼저 겪음. 기각.

## 결과
- 장점: 한 번의 개발로 세 환경 지원. 선생님은 안 되는 것을 미리 안내받는다.
- 단점: 환경 지원표를 공식 문서에 맞춰 계속 갱신해야 한다(README 표는 2026-11-18 기준). Claude 앱은 내 컴퓨터 폴더에 직접 못 쓰고, Codex는 인터넷 설정을 선생님이 켜야 하는 등 경험 차이가 남는다.
