## 먼저 만들 5가지 (자유 창작 20분에 「와~」를 안정적으로)
1. **슬라이드 스킨 확장 + 닮음 검사**: 가장 많이 나올 요청의 다양성(2.9 → 4) 상승.
2. **게임 스타일 자동 선택 개선**: 주제별 허용 스타일, 세션 내 중복 제외, 대비·색 부족 자동 재시도.
3. **교실 도구 무기(`teacher-class-tools`)**: 타이머·뽑기·대진표는 AI 단독으로 이미 3.5~4.5점, 틀로 굳히면 항상 같은 품질.
4. **포스터·카드뉴스 무기(`teacher-design`)**: 21·22 틀과 PNG 저장. 시각 임팩트가 큰 요청.
5. **범용 점검기 + 그림 점검 확장(`check_html`/`design_review`)**: 새 무기와 AI 단독 경로 모두의 바닥을 올림 (무손실 원칙의 「점검기는 그대로 적용」을 실제로 지키는 도구).
