## 오늘 쓰는 비유 (덱·노트·안내서 모두 같은 말)
AI를 모르는 선생님께 회사·앱 이름은 어려워서, 개념을 말할 때는 요리 비유만 써요.

| 진짜 | 비유 |
|---|---|
| AI(모델) | 요리사 |
| AI 회사 | 식당 (덱에서는 「식당 A·B·C」) |
| AI 앱 | 그 식당의 주방 |
| 앱에 들어 있는 기능 | 그 주방의 레시피 책 · 도구 |
| 하네스 | 레시피 + 밀키트 + 주방도구 + 시식 + 위생 규칙 |
| 프롬프트 | 주문서 (누구에게 · 어디에 · 어떤 느낌 · 어떤 재료) |
| 일반 채팅창 | 주문만 받는 카운터 (파일은 「주방」 화면에서 만들어요) |

- **실습 장(16~17장)만** 실제 앱 이름을 작게 한 번 적어요: 「우리 식당 = Claude 앱」, 개인 계정은 「Codex」 앱. 선생님이 실제로 눌러야 하니까요.
- 식당 A·B·C가 어느 회사인지는 화면에서 말하지 않아요. 발표자용 대응표는 [deck-v2-NOTICE.md](deck-v2-NOTICE.md) 「상표 · 로고」.

오늘의 한 줄: 「바로 만들어 말고, 기획부터 같이 해 줘」

## 시간표 (덱 발표자 노트의 분과 같아요)

| 시간 | 장 | 주제 | 내용 |
|---|---|---|---|
| 0~4분 | 1~5 | 여는 말 · 오늘의 단어 | 표지, 여기저기서 들리는 AI, 진입장벽, 옛날 이야기, 「하네스」 |
| 4~7분 | 6~7 | 하네스의 유래 · 식당들도 | 말 사진 → 식당마다 요리사는 비슷하고 주방에 갖춘 하네스가 달라요 |
| 7~15분 | 8~12 | 같은 부탁, 다른 결과 | 같은 부탁 4개, 왼쪽 그냥 AI(요리사 혼자) / 오른쪽 하네스 AI |
| 15~19분 | 13~15 | 김치볶음밥 그림책 | 레시피·도구를 받은 요리사 로봇 → 바닥이 셰프 레시피에서 시작 → 하네스는 누가 만드나 |
| 20~27분 | 16~18 | 실습 1~3 | 우리가 쓸 식당 고르기 → 파일을 만드는 주방 열기 → 링크 붙여 넣고 한 줄(5분 타이머). 막히면 안내서 1쪽 zip 올리기 |
| 27~40분 | 19 | 실습 4: 두 화면 비교 | 같은 주문서를 두 화면에 넣고 나란히 보기 |
| 40~56분 | 19 | 모둠 미션 | 「○○ 기획부터 같이 해 줘」 → 고르기 → 고치기 → 완성 → 폰으로 공유. 메뉴판: 게임·슬라이드·영상·수업 도구·데이터 보고서·가정통신문 법 확인. 코디네이터 순회 |
| 56~60분 | 20~21 | 마무리 | 모둠 1곳 자랑 1분, 「그래서, 같이 쓰려고 준비했어요」, 가져가실 세 가지, 책임은 선생님, 사이트 QR |

### 시간이 남으면 · AI 커닝 (약 10분, 22~33장 + 37장)
마무리까지 끝낸 뒤 10분 넘게 남을 때만 해요. 대본: [cheating-segment.md](cheating-segment.md). 뉴스 보도 수준의 갈래만 말하고, 기기 이름·숨기는 요령·연결 방법은 말하지 않아요.

### 시간이 남으면 · 시연 (약 5분, 발표자 혼자)
AI 커닝 구간 끝, 「한 장으로 다시」(33장) 다음·「다시 한 번, 결론」(37장) 앞 (덱 34~36장). 대본·인터넷이 안 될 때 대안: [`cheating-segment.md`](cheating-segment.md) 「시연」.

| 분 | 장 | 내용 |
|---|---|---|
| +0~1 | 34 시연 흐름 | 찍고 → 보내고 → 풀고 → 받기, 큰 시계 소개 |
| +1~3 | 35 예시 문항 | T 켜고 화면을 휴대폰으로 찍기 → 노트북으로 보내기 → AI 풀이 → 휴대폰으로 받기, 멈춤 |
| +3~5 | 36 어느 단계에서 끊을까 | 단계별 감독이 살필 것 4줄 + 「선은 미리」 |

시간이 10분보다 적게 남으면 시연만 하고(34~36장), 앞의 AI 커닝 설명은 건너뛰어도 돼요.

## 가져가실 세 가지 (21장과 같은 말)
1. **그냥 시키지 않기:** 도구와 레시피가 있는 하네스를 켜고 시작.
2. **한 번 제대로 말하기:** 주문서처럼 누구에게 · 어디에 · 어떤 느낌 · 어떤 재료.
3. **끝나면 확인:** 사실·숫자·출처는 원문으로, 학생 정보는 넣지 않기. 마지막 책임은 선생님께.

## 시간이 모자라면
- 같은 부탁, 다른 결과(8~12장)를 4개 중 2개만 (−4분)
- 모둠 미션을 줄이고 실습 4 비교를 한 모둠 화면만 같이 보기 (−5분)
- AI 커닝·시연(22~37장)은 시간이 남을 때만. 모자라면 통째로 뺌
