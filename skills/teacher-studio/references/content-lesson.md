# Lesson content — what a 수석교사 checks (slides, games, worksheets, activities)

Use for any material a teacher puts in front of students. This decides the content; the medium recipe (`teacher-slides/references/content-slides.md`, `teacher-game/references/content-items.md`) fits it to the screen. Principles and choices only: derive the structure from this lesson's objective every time, never from an example.

## Steps
1. **Pin the target.** From the request and attachments get: 학년 · 과목 · 단원/차시 · 수업 시간 (초 40분 · 중 45분 · 고 50분 unless told) · where it sits in the unit (도입 차시 / 개념 / 적용 / 정리·평가).
   - Teacher gave a textbook page, 지도서 or 학습지 → that is the source of truth for terms, order and scope.
   - Nothing given and it changes the content → ask once (학년 and 단원 only). 「알아서」 → state the assumption in one line.
2. **Link to the 성취기준 without inventing it.**
   - Teacher supplied the code or text → quote it exactly.
   - Search available → read it on NCIC (https://ncic.re.kr, 「2022 개정 교육과정 자료 → 원문」) and copy code + sentence; also read that standard's 「성취기준 해설」 and 「성취기준 적용 시 고려 사항」 for scope limits.
   - Neither → write the 학습 목표 only and add 「성취기준 번호: 확인 필요」. **Never compose a code from memory.**
   - Which curriculum applies (2026학년도): 2022 개정 for 초1-6 · 중1-2 · 고1-2; **중3 · 고3 are still on 2015 개정** until 2027. 3. 1. If the grade is 중3/고3, do not use 2022 codes. Recompute this from the 학년도 the material is for, not from today's date.
   - The 2022 text has been partly amended since (국가교육위원회 고시 제2026-1호, 시행 2026. 3. 1.). When a standard, 시수 or 이수 기준 matters to the output, read the current text and its 적용 시점, not a 2022 copy.
   - Keep the official sentence as written. Standards do not all end the same way (some subjects use 「~한다」, others 「~할 수 있다」); do not normalise the ending.
3. **Write 1-3 학습 목표 that can be checked.**
   - Form: 〈조건〉에서 〈내용〉을 〈관찰되는 행동〉할 수 있다. Verbs you can see or mark: 말한다 · 고른다 · 구한다 · 나타낸다 · 비교한다 · 분류한다 · 설명한다 · 예를 든다 · 만든다 · 고쳐 쓴다.
   - 「이해한다 · 안다 · 느낀다 · 기른다」 alone are not checkable → add the evidence (「…을 자기 말로 설명한다」).
   - Each objective names one of 지식·이해 / 과정·기능 / 가치·태도; do not stack all three into one sentence.
   - Test: for each objective, can you name what you would see or hear that proves it? Pick the evidence that fits the objective: a question (knowing, calculating), an observation of doing (실험 조작, 토론, 연주, 운동), an explanation in the student's words (reasoning), or a product (글, 작품, 보고서). A single right answer is weak evidence for a skill that needs doing or reasoning; do not force every objective into one quiz item.
4. **Decide the evidence before the activities** (backward design): the questions, observation points or product that will show each objective was met. Activities exist to get students there.
   - For each piece of evidence write the **next move**: what the teacher does when most are right, when a known wrong idea appears, and when the answer is right for the wrong reason (ask 「어떻게 알았어요?」 before moving on). A check with no planned next move is only a score.
5. **Find the 오개념 and aim at it.**
   - Source order: teacher's note → 지도서/성취기준 해설 → your subject knowledge of typical error types (일상어와 교과 용어 혼동 · 과잉 일반화 · 절차만 외움 · 그림/표 잘못 읽기 · 원인과 결과 뒤바꿈 · 단위 혼동).
   - If you cannot name a real misconception for this content, say so; do not make one up to fill a slot.
   - Each targeted misconception gets: one moment that exposes it (a question where it produces a wrong answer), then the explanation that contrasts it with the correct idea. Never present the wrong idea as text without marking it wrong on the same screen.
6. **Lay out 도입 · 전개 · 정리 as a rhythm, not three labels** (time shares are heuristics: ≈ 10-15% · 70-75% · 10-15%).
   - 도입: one hook that needs today's idea to resolve (a puzzle, a prediction, a disagreement, 전시 학습 one-question recall). Then the objective in student words. If the hook does not come back in 정리, it was decoration.
   - 전개: chunks of 「short input → students do something → check」. Why: attention and working memory fade during long listening, and errors found late cannot be fixed in class. As a default keep one input stretch to about 5-7 minutes for 초·중 (shorter for 저학년; a demonstration, a reading or a film clip that needs longer is fine if students have a task while it runs). Avoid two input chunks in a row. Order by dependency: what must be known before what.
   - 정리: students produce the summary (answer the hook, 한 문장 정리, exit question); the teacher's recap comes after theirs. End with what comes next.
7. **Design each activity on purpose.**
   | if the task | then |
   |---|---|
   | has one right procedure to practise | 개별, then 짝 점검 |
   | benefits from different views or roles, or the product needs several hands | 모둠 (3-4명), each member with a named job and an individual check afterward |
   | is a quick check of everyone | 전체 (동시 응답: 손가락 · 카드 · 화면 선택), not one volunteer |
   | needs thinking before talk | 혼자 생각 → 짝 → 전체 |
   Every activity states: 무엇을 만드는가(product) · 시간 · 준비물 · 끝났을 때 할 일 · 빨리 끝난 학생의 다음 과제. An activity without a visible product is discussion time, so plan it as that.
8. **Make 수준별 variants of the same objective.**
   - 기초: same target, more support (worked example, 단계 나눔, 낱말 도움, 선택지 줄임, concrete numbers). Not less thinking, not a different lesson.
   - 심화: same target, less support or more transfer (new context, 이유 설명, 반례 찾기, 문제 만들기, 오류 찾아 고치기). Not more of the same problems, not next unit's content.
   - Label neutrally (도전 1·2, 길 가·나), never 「못하는/잘하는」. All students can reach the core question.
9. **Write 확인 질문 with answers.**
   - At least one per objective, placed where a wrong answer can still be fixed in class (not only at the end).
   - Each has: 정답 · 한 줄 「왜」 · what each wrong option reveals. Mix recall with at least one that needs the idea applied.
   - Options plausible, same kind, similar length; one carries the targeted misconception. Detail rules: `teacher-game/references/content-items.md`.
10. **Control cognitive load.**
    - One new idea per screen; a figure and its words on the same screen, next to each other.
    - Do not put the same sentence on screen that the teacher will say aloud; the screen carries the figure or the key phrase, the note carries the script.
    - New term → first appearance with its meaning. Each new term costs attention, so introduce only the ones this period's objective needs (for 초등 that is usually 2-3; a vocabulary lesson or 중·고 content may need more, then group them and give practice for each).
    - Safety and procedure instructions (실험 · 실습 · 체육) are the exception to brevity: keep every step and condition, in order, where students can find it while working.
    - Decoration that does not carry meaning (clip art, mascot lines, unrelated trivia) is removed.
11. **Match vocabulary to the grade.**
    - Use the textbook's word for the concept. Where textbooks differ, mark 「확인 필요」.
    - 초 1-2: everyday words, one clause, 한자어 concept words only if they are the target. 초 3-6: textbook terms explained once. 중·고: textbook terms as given; define only new ones.
    - Examples and contexts come from that age's life (not 직장 · 대출 · 운전 for 초등), and vary them: do not reuse the same context across questions.
    - **영어 only:** the curriculum has an official 기본 어휘 목록 with 학교급별 권장 어휘 and 사용 지침 (2022 개정 영어과, 별책 14 [별표 3]). For English materials check words against it or the teacher's textbook list; do not judge level by feel. This rule does not apply to other subjects.
    - Other subjects: no official grade-level word list was found (**unverified** whether one exists); the textbook is the reference.
12. **Tie to evaluation, and know which kind this is.** Ask or infer: is this a check during learning, or does it count toward 성적 (지필 · 수행평가)? They need different checks.
    - **수업 중 확인 (not graded):** purpose is to decide the next teaching move. Needs: fit to today's objective, a clue in each wrong answer, the planned next move (step 4). Speed, fun and luck are acceptable here.
    - **성적 반영 평가 (graded):** the material is a draft for the teacher's own procedure, never final by itself. It needs all of:
      - 출제 범위 = what was actually taught and the 성취기준 (nothing beyond the taught curriculum; the teacher confirms the scope),
      - 채점 기준 with 배점, 부분 점수 and 허용 답안 (other valid solutions, 유사 답안, 표기 차이),
      - difficulty that comes from the target skill, not from long reading in a maths item, timing pressure, colour or motor skill,
      - 평가 조정 for students who need it (시간 · 방식 · 보조 도구), decided by the school,
      - 교차 검토 by another teacher and the school's 학업성적관리 절차 (결과 확인 · 이의 신청).
      Which of these are mandatory, and how, is set by 법령, 교육청 지침 and 학교 규정: say 「학교 학업성적관리규정 확인 필요」 and route legal questions to `teacher-law`; do not state the rule from memory. A game score is never used as a grade.
    - For a 수행 product: 2-4 criteria, each level described by observable features. For official 성취수준 wording use the curriculum documents; do not invent level descriptors as if official.
13. **Verify facts** (CONTENT-RULES rule 4): every 연도 · 수치 · 단위 · 정의 · 공식 · 인명 · 지명 · 맞춤법. Compute answers yourself, twice, by a different route when possible. History and science values → source or 「확인 필요」. Then give the teacher the answer key with a line: what to confirm against their textbook.

## 전문가 점검표
- [ ] 성취기준 is quoted from a source or marked 「확인 필요」; the curriculum year matches the grade (중3 · 고3 = 2015 개정 in 2026).
- [ ] Each 학습 목표 has an observable verb and matching evidence of the right kind (question / observation / explanation / product), with a next move for likely responses.
- [ ] 도입's hook is answered in 정리 (or the file says why this lesson opens differently).
- [ ] Input stretches are short enough for this class and each is followed by students doing something; any longer stretch has a stated reason and a task.
- [ ] In-class check or graded assessment is stated; a graded one has 범위 · 채점 기준 · 허용 답안 · 조정 · 교차 검토 noted and is labelled a draft for the school's procedure.
- [ ] Safety and procedure steps are complete and findable during the activity.
- [ ] At least one real 오개념 is exposed and corrected (or the file says none was identified).
- [ ] 기초 · 심화 variants aim at the same objective and are neutrally labelled.
- [ ] Every question has 정답 + 「왜」; every numeric answer was recomputed; no question has two defensible answers.
- [ ] One new idea per screen; new terms defined at first use; the screen does not duplicate the spoken script.
- [ ] Every activity states product · time · 준비물 · early-finisher task; total time fits the period with ≈ 3 minutes of slack.
- [ ] Contexts are age-appropriate and varied; no stereotype by gender, family form, region or ability; no real student named.
- [ ] Third-party text/images (교과서 지문, 시, 사진) have a stated basis → `teacher-law` when unsure.
- [ ] The teacher gets: 정답표, 준비물, 시간 계획, and the list of 「확인 필요」 items. An unverified answer or safety condition keeps the whole material a 「교사 초안」 (CONTENT-RULES, Release status).
