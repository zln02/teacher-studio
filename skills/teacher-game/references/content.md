# 문제·오답·해설 만들기

- **선생님 자료가 있으면 그 안에서만** 낸다. 없으면 일반 지식으로 만들고 불확실한 줄은 표에 「확인 필요」.
- 학년 수준: 중1~3 교과서 용어 그대로. 교과서마다 다른 용어(반어/역설, 진동수/주파수)는 「확인 필요」에 적는다.
- 문제 문장: 한 문장, 25자 안팎(칠판), 부정 질문(「아닌 것은?」)은 10개 중 2개 이하.
- 오답 보기: 같은 종류에서(인물이면 인물), 길이 비슷하게, 흔한 오개념 하나 포함. 웃긴 보기는 한 개까지.
- 해설: 한 줄, 「왜」를 말한다. 오답 학생이 바로 이해하게.
- 단어 게임: 오답은 같은 목록의 다른 뜻에서 뽑아도 된다. 예문을 지어내지 않는다.
- 시·소설: 저작권이 끝난 작품(예: 김소월)은 시구 인용 가능. 현대 작품은 선생님이 붙여 준 부분만.
- 역사·과학 수치(연도·단위)는 두 번 확인. 연표는 같은 해 사건 순서까지 확인.
- 표 끝 문장: 「정답이 맞는지 확인해 주세요. 고칠 곳을 말씀하시거나 '좋아'라고 하시면 만들게요.」
