# 연수 계획서

| 항목 | 내용 |
|---|---|
| 연수명 | AI를 진짜 잘 쓰는 사람들은 이렇게 써요: 재료와 도구를 쥐여 주는 AI 활용 (실습형) |
| 강사 | AI교육코디네이터 박진영 [소속 입력] |
| 대상 | AI를 처음 쓰거나 업무에 막 쓰기 시작한 초·중·고 교사 [인원 입력] |
| 일시·장소 | [날짜] [시간] 60분 · [장소] |
| 방식 | 강의 15분 + 시연 10분 + 모둠 실습 35분 (모둠당 공용 PC 1대, 대표 1명이 입력) |
| 비용 | 없음. 도구는 돈 받는 것 없는 무료 공개 도구(재능기부)이며 판매·홍보 목적이 아님 |

## 연수 목표
1. AI가 왜 헤매는지 이해한다 (맨몸 AI vs 도구를 쥔 AI).
2. AI에게 재료(사진·PDF·엑셀·예시)와 도구를 쥐여 주는 법을 익힌다.
3. 직접 설치하고 내 업무에 바로 써 본다.

## 내용과 시간표
| 시간 | 내용 | 방식 |
|---|---|---|
| 0–5 | 오프닝, 연수 목표 3가지 | 강의 |
| 5–15 | AI가 헤매는 이유 (맨몸 모델 vs 무기를 쥔 모델), 최근 AI 회사들의 도구·스킬·에이전트 흐름, 공개 도구 소개 | 강의 |
| 15–25 | 같은 요청을 두 화면(맨몸 AI / 도구 갖춘 AI)에서 나란히 시연, 재료를 주면 달라지는 것 | 시연 |
| 25–35 | Claude 앱에 도구 설치 (모둠 PC, 단계별 따라 하기) | 실습 |
| 35–55 | 만들고 싶은 것 자유 제작 (수업 게임·슬라이드·안내문 등), 우수 결과 공유 | 실습 |
| 55–60 | 정리, 가져갈 것(포켓 카드·QR), 소감 작성 | 정리 |

선택 구간(2부, 연수 대상이 감독 교사일 때 10분): [AI 시험 부정행위, 감독교사가 알아야 할 것](ai-cheating/cheating-segment.md)

## 준비물
- 모둠당 공용 PC 1대 (크롬, 인터넷), 빔프로젝터·화면
- 선생님 본인 Claude 계정(만 18세 이상) 로그인
- 도구 파일(zip 8개) 또는 접속 가능한 GitHub 주소: https://github.com/zln02/teacher-studio
- 시연 백업 녹화·결과 파일, 포켓 카드·메뉴판 인쇄물, 설치 QR 출력본
- 참가자가 가져올 것(선택): 평소 하는 업무 한 가지, 참고 자료(학습지·지난 안내문)

## 유의 사항
- 학생 이름·사진·성적 등 개인정보는 입력하지 않는다 (가명 사용).
- AI 서비스는 서비스별 이용 나이가 있어 학생은 직접 사용하지 않는다.
- AI 결과는 초안이며 최종 확인과 책임은 교사에게 있다.

## 평가와 소감 방법
- 연수 끝 3분, 구글폼 또는 종이 [QR 삽입]. 연수 목표 3가지 기준:
  1. 5점 척도: 「AI가 왜 헤매는지 이해했다」
  2. 5점 척도: 「AI에게 재료와 도구를 주는 방법을 알았다」
  3. 5점 척도: 「직접 설치하고 내 업무에 써 볼 수 있었다」
  4. 서술: 오늘 만든 것 / 앞으로 써 보고 싶은 일 / 바라는 점
- 실습 성과: 모둠별 만든 결과물 수(출력 시 [입력]), 설치 완료 모둠 수 [입력]
- 기대 효과: 업무에 AI를 활용하는 자신감, 자료 제작 시간 단축 [실측 전이므로 수치 없음]
