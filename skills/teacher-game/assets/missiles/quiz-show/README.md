# 퀴즈쇼 미사일 (quiz-show)

## 언제 쓰나
- 반 전체가 칠판 앞에서 모둠 대결로 푸는 객관식·OX 퀴즈 (단원 정리, 복습, 수업 시작 5분)
- 진행자 캐릭터와 무대 연출이 필요한 「퀴즈쇼·골든벨·우주 퀴즈」 분위기 요청

## 선생님 말 예시
- 「독도 단원 끝났으니까 퀴즈쇼처럼 모둠 대결 10문제 만들어 줘」 → tv-studio
- 「중2 품사 골든벨 하고 싶어, 개인전으로」 → golden-bell
- 「과학 별 단원 우주 느낌 퀴즈, 맞히면 뭔가 켜지게」 → space-quiz

## content.json 형식 (바뀌는 것만)
```json
{ "title": "품사 골든벨", "subtitle": "중2 국어 · 문법", "teams": 0, "timer": 20,
  "items": [
    { "type": "mc", "q": "문제", "choices": ["보기1","보기2","보기3","보기4"], "answer": 2, "exp": "해설 한 줄" },
    { "type": "ox", "q": "OX 문제", "answer": 0, "exp": "해설" } ] }
```
- `answer`: 객관식은 0부터 센 정답 번호, OX는 0=O·1=X. 보기는 2~6개. `exp`는 한 줄 해설(정답판에 나옴).
- `teams`: 0(개인)·2·3·4 / `timer`: 문제당 초(0이면 없음) / `bonusEvery`: 몇 문제마다 2배 보너스(기본 4)
- 문제는 시작할 때마다 섞임. 틀린 문제는 결과 화면 「틀린 문제만」으로 다시 풀기.
- 선생님이 바꿀 만한 `world` 키 (안 쓰면 스킨 기본값):
  - `hostName` 진행자 이름, `howto` 시작 화면 안내 한 줄
  - `lines.{title,start,q,teamQ,bonus,last,retry,wait,correct,wrong,timeout,reveal,finale}` 진행자 말풍선 (여러 개면 무작위, `{team}` = 팀 이름)
  - `finaleTitle`·`finaleSub` 피날레 문구 (`{n}` 맞힌 수, `{total}` 전체)
  - tv-studio: `onAirText`, `signText`(박수 전광판), `soloLabel`(개인전 단상 이름)
  - golden-bell: `boardText`(학생 보드 글자) / space-quiz: `stationName`, `powerLabel`
  - `colors.*` 그림·패널 색 (스킨 파일에 전체 목록)

## 스킨
- **tv-studio** 방송국 퀴즈쇼 — LED 벽·움직이는 조명, 마이크 든 진행자, 팀별 LED 단상. 정답이면 APPLAUSE 전광판 점등+박수, 피날레는 우승 단상에 왕관.
- **golden-bell** 강당 골든벨 — 붉은 막·나무 무대, 안경 쓴 진행 선생님, 학생들 보드. 정답마다 금종이 울리며 점점 밝아짐, 해설은 칠판 글씨로 써짐, 피날레는 큰 금종 3번 타종.
- **space-quiz** 우주 정거장 퀴즈 — 행성이 보이는 큰 창, 로봇 진행자, 아래쪽 정거장 모듈. 정답마다 모듈에 불이 켜지고 전력 게이지 상승, 피날레는 모듈 점등 후 워프.

## 크기·사용 환경
- 1920×1080 무대(엔진이 화면에 맞춤). 전자칠판 팀전 기준: 문제 60~76px, 보기 48px, 버튼 높이 120px 이상, 해설 36px.
- 태블릿 개인전: `teams:0`, `teamChoice:false`, `timer:0` 권장. 가로 화면.
- 오른쪽 위 ⚙️ 선생님 메뉴: 다음으로(건너뛰기)·정답 보기·시간 +10초·점수 조정. Space = 다음.
- 문제 30자 넘으면 두 줄, 보기 12자 넘으면 두 줄로 자동 줄바꿈. 문제는 60자 이내 권장.

## 확인된 것 (2026-11-18)
- 세 스킨 모두 fire.py PASS (각 약 150KB), 헤드리스 크롬 1280×720으로 제목→끝→피날레→결과→틀린 문제만→처음으로 플레이, 페이지 오류 0.
- 팀 0·2·3·4 모두 확인, 오답 1회·선생님 메뉴 정답 보기·다음으로 동작, 보너스 2배·타이머 시간초과 동작.
- 장면 전환 중 연타해도 이전 화면 버튼이 다음 문제에 답하지 않음.
- 알려진 한계: 그래픽이 약한 기기에서는 엔진이 「가벼운 모드」로 자동 전환(원래 부품과 같음). 보기 7개 이상은 지원 안 함.
