# 따로 하는 구간: AI 커닝, 미리 막기 (약 8분 · 선택 · 쉬운 말)

발표: AI교육코디네이터 박진영 · 슬라이드: [ai-cheating-deck.html](ai-cheating-deck.html) 8장 (소스 `deck-src/slides-e.html`)

- **목표:** 「방법은 달라도 순서는 같아요」를 알아듣고, 의심이 들 때 할 일과 평가 준비를 돕는 다섯 가지(보조책)를 가져가기.
- **톤:** 「우리 학교도 미리 준비해요」. 누구를 의심하는 말투가 아니게, 무력감을 주지 않게.
- **안전선:** 기기 · 제품 이름, 숨기는 법, 연결 · 설정 방법, 안 들키는 법, 몸짓과 방식을 잇는 설명은 말하지 않아요. 질문이 나오면 「그건 몰라도 준비할 수 있어요」.
- **화면에 없는 것:** 뉴스 숫자 · 날짜, 법 설명. 기기 보관 · 감독은 「학교 시험 운영 규칙에 따라요」.

## 시간표 (덱을 연 뒤부터 · 말할 문장은 장마다 발표자 노트 N)
| 분 | 장 | 내용 |
|---|---|---|
| 0~0.5 | 1 표지 | AI 커닝, 미리 막기 · 오른쪽에 다섯 단계 |
| 0.5~1 | 2 미리 준비 | 큰 글자 「우리 학교도 미리 준비해요」 → 「시험장에서 AI 기기를 이용한 부정행위가 보도되고 있어요」 → 「의심하자는 게 아니에요. 평가 준비를 함께 점검해요」 |
| 1~2.5 | 3 순서 | 큰 글자 「순서는 같아요」 → 지도: 찍어요 → 보내요 → AI가 풀어요 → 돌아와요 → 써요 → 「앞뒤는 교실 안 · 평가 준비와 감독을 함께 챙겨요」 |
| 2.5~3.5 | 4 의심이 들 때 | 허용 물품 · 감독 규칙은 미리 알리고 똑같이 / 본 사실만 기록 / 공개 지목 안 함 / 학교 절차로 확인 |
| **3.5~5.5** | **5 다섯 가지** | **가운데 장.** 아래 A4 한 장 |
| 5.5~6.5 | 6 AI 풀이 참고 | 흔한 문제 → 「몇 초 만에 정답」 ↔ 자료를 주고 과정 묻기 → 「AI가 맞힌다고 나쁜 문항은 아니에요」. 시간이 남으면 선택 시연 +2분 (지어낸 예시만) |
| 6.5~7.5 | 7 이렇게 말하면 돼요 | A형 B형 · 쪽 번호 · 같은 오답 정리 부탁 → 「오늘은 가상 문제 · 가상 답안으로만」 |
| 7.5~8 | 8 한 장으로 | 다섯 가지 그대로 · 마무리 |

모자라면 3 → 5 → 8만 해도 돼요.

## 다섯 가지 (A4 한 장 · 모두 보조책)
1. **AI 풀이도 참고해 점검하기** — AI가 맞힌다고 나쁜 문항은 아니에요. 목표 · 난이도 · 설명 요구를 다시 봐요.
2. **자료를 주고 과정 묻기** — 필요한 기록표 · 자료를 주고, 근거와 과정을 설명하게 해요.
3. **A형 B형 (순서만)** — 문항 · 배점은 같게, 순서만 바꿔요. 그대로 옮기기 어렵게 하는 보조책 · 정답은 직접 확인.
4. **쪽 번호 · 형 표시** — 배부 · 회수 때 누락을 확인해요.
5. **같은 오답 살펴보기** — 흔한 오개념일 수도 있어요. 겹침만으로 판단하지 않아요.

- 기기 보관과 감독은 학교 시험 운영 규칙에 따라요.
- 의심이 들 때: 규칙은 미리 알리고 똑같이 · 본 사실만 기록 · 공개 지목 안 함 · 학교 절차로 확인.
- 연습은 가상 문제 · 가상 답안으로만. 실제 시험 문제와 답안은 학교가 허용한 도구와 처리 기준을 확인한 뒤.
