가져가실 다섯 단계

  1. 1주문서 쓰기누구에게 · 어디에 · 어떤 느낌 · 어떤 재료
  2. 2기획 같이 하기AI가 묻고 내가 고르기 · 「기획부터 같이 해 줘」
  3. 3만들고 한 번 고치기「여기만 고쳐 줘」 한 번 더
  4. 4확인하기사실·숫자 / 남의 개인정보(학생·학부모·교직원·가족 등) / 저작권
