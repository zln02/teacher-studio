# 포켓 카드 (책상 위 한 장)

AI는 이미 실력 좋은 요리사예요. 중간에 지치지 않게, 주방(도구)을 갖춰 주고 주문을 정확히 해요.

## 주문서 4가지 · 누·어·느·재
| | 물음 | 예 |
|---|---|---|
| 누 | 누가 먹나요 (누구에게) | 5학년 학생들 |
| 어 | 어떤 자리인가요 (어디에 쓸지) | 수업 시작 5분 |
| 느 | 어떤 맛인가요 (느낌) | 신나게 |
| 재 | 냉장고에 뭐가 있나요 (재료·첨부) | 우리 학습지 |

한 줄 예: 「5학년 · 수업 시작 5분 · 신나게 · 첨부한 학습지로 · 태양계 퀴즈 5개」

## 간 맞추기 (한 번에 하나씩)
- 「더 크게」
- 「더 쉬운 말로」
- 「더 따뜻하게」
- 「3번만 고쳐 줘」
- 「처음 것이 더 나았어. 되돌려 줘」

## 꼭 지킬 3가지
1. 알레르기 정보 지키기: 학생 이름·사진·성적은 넣지 않아요.
2. 원산지 확인: AI가 말한 사실·숫자·출처는 내가 확인해요.
3. 상차림 책임은 나: 최종 책임은 선생님. 공개하기 전 저작권 확인.

## 막히면 이렇게 말하세요
1. 「필요한 게 더 있으면 먼저 한 번에 물어봐 줘.」
2. 「두 번 고쳐도 안 되면, 다른 방법으로 바꿔서 해 줘.」
3. 「방금 답이 맞는지 근거와 출처를 같이 알려 줘.」
