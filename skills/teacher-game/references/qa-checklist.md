# 최종 점검 (check_game.py 다음에, 또는 실행 못 할 때 손으로)

## 자동 (작업 공간이 있으면)
1. `python3 scripts/check_game.py game.html` → FAIL 0
2. 브라우저로 한 판: 크롬 헤드리스가 있으면 제목 → 시작 → 정답 1번·오답 1번 → 끝까지 → 결과 → 다시 하기. 콘솔 오류 0 (글꼴 로딩 실패는 무시).
3. 1280×720 캡처를 직접 보고: 글자 겹침, 잘림, 반투명 카드 위 글자, 버튼 가림.
