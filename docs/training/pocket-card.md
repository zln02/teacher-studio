# 포켓 카드 · AI 활용 꿀팁 7가지 🍯

AI는 실력 좋은 요리사예요. 정확히 주문하고, 필요하면 주방(도구)을 갖춰 줘요.

1. **누·어·느·재로 주문하기** (요리사에게 주문하듯)
   - 누(누구에게) · 어(어디에 쓸지) · 느(어떤 느낌) · 재(어떤 재료)
   - 예: 「5학년 · 수업 시작 5분 · 신나게 · 첨부한 학습지로 · 태양계 퀴즈 5개」
2. **냉장고 재료 주기**: 사진·PDF·엑셀을 같이 올려요. (올리기 전에 학생 정보는 가려요)
3. **간 맞추기**: 한 번에 끝내지 말고 한마디씩
   - 「더 크게」「더 쉬운 말로」「더 따뜻하게」「3번만 고쳐 줘」「처음 것이 더 나았어, 되돌려 줘」
4. **먼저 묻게 하기**: 「필요한 거 먼저 물어봐 줘」
5. **가짜 메뉴 조심**: 「출처도 같이 알려 줘」 → 출처 하나는 직접 열어 확인
6. **알레르기 정보 지키기**
   - 학생 이름·사진·성적은 넣지 않아요 (가명 학생A)
   - 공개 전 저작권 확인
   - 최종 책임은 나 (AI는 초안)
7. **무기 쥐여 주기**: 도구를 갖춘 AI는 덜 헤매요. 교사 스튜디오(무료): https://github.com/zln02/teacher-studio

## 막히면 이렇게 말하세요
1. 「필요한 게 더 있으면 먼저 한 번에 물어봐 줘.」
2. 「두 번 고쳐도 안 되면, 다른 방법으로 바꿔서 해 줘.」
3. 「방금 답이 맞는지 근거와 출처를 같이 알려 줘.」
