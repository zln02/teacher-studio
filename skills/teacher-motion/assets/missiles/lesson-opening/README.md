# 수업 시작 화면 미사일 (lesson-opening)

## 언제
- 종이 치고 수업을 시작할 때 칠판·TV에 띄우는 10~15초 화면: 카운트다운 5→1 → 「오늘의 주제」 큰 제목 + 목표 한 줄(+오늘의 순서) → 선생님이 누를 때까지 잔잔하게 움직이며 대기
- 누르면(클릭·Space·Enter·→·PageDown, 발표용 리모컨 OK) 제목 카드가 위쪽 머리띠로 접히고 「수업 시작!」 → 칠판처럼 비워진 화면에 주제만 남음
- 카운트다운 중에 누르면 바로 제목으로 건너뜀. R = 처음부터

## 선생님 말 예시
- 「수업 시작할 때 띄울 거, 애들 집중시키게 5초 카운트다운」 → bold-pop
- 「1교시라 차분하게 시작하고 싶어, 오늘 주제랑 목표 보이게」 → calm-paper
- 「매 시간 쓰게 주제만 바꿔서 만들어 줘」 → 같은 스킨에 content.json만 교체

## content.json 형식 (바뀌는 것만)
```json
{ "count": 5,
  "label": "오늘의 주제",
  "topic": "일차방정식, 저울로 풀어 볼까?",
  "goal": "등식의 성질로 일차방정식을 풀 수 있다",
  "meta": "1학년 수학 · 3단원",
  "items": [ { "text": "저울 실험" }, { "text": "모둠 문제" }, { "text": "퀴즈" } ],
  "world": { "ready": "곧 수업이 시작돼요!", "goalLabel": "목표", "stepsLabel": "오늘의 순서",
             "hint": "화면을 누르면 수업 시작", "start": "수업 시작!" } }
```
- `count` 3~10 (기본 5). `topic` 30자 이내 권장(길면 자동 축소). `goal`은 한 줄 목표(비우면 빠짐).
- `items`(오늘의 순서)는 0~5개, 각 8자 이내. 없으면 순서 줄이 빠짐. `meta`도 선택.
- `world`의 문구는 비우면 그 요소가 빠짐(`ready` 안내, `hint` 누르기 안내, `start` 시작 인사).

## 스킨
- **bold-pop** 밝고 힘찬 팝: 숫자마다 배경색이 원형으로 확 바뀜, 검은 테두리 스티커 숫자가 튕기며 등장·튀어 나감, 땡땡이·도형 무늬가 둥둥, 굵은 그림자 카드, 시작하면 색종이 폭죽. 글씨: Black Han Sans + Noto Sans KR.
- **calm-paper** 차분한 종이 공작: 종이 언덕·구름이 천천히 흔들리고 카운트다운 동안 종이 해가 떠오름, 숫자는 종이 카드가 넘어가듯 넘김, 테이프 붙인 메모 카드, 종이 조각이 살랑 떨어지며 시작. 글씨: Jua + 고운바탕.
