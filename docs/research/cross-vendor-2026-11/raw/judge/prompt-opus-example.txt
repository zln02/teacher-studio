너는 공정한 심사위원이야. 같은 요청에 대해 서로 다른 4곳(A, B, C, D)이 만든 결과물이 있어. 어느 쪽이 어떤 AI·어떤 방식으로 만들었는지는 모르고, 알려 하지도 마.

[요청]
중학교 3학년 역사 '조선 후기 실학의 등장' 수업용 PPT 만들어 줘 (10장 정도, 파워포인트 파일로)

[보는 법] 현재 폴더에 A.png, A2.png, B.png, B2.png, C.png, C2.png, D.png, D2.png 가 있어. Read 도구로 모두 직접 열어서 봐. 각 그림은 한 결과물의 화면을 순서대로 이어 붙인 것이고, 왼쪽 위에 글자(A~D)가 있어. 「A (2)」처럼 번호가 붙은 그림은 같은 결과물의 뒤쪽 장이야.
결과물 형식: .pptx 슬라이드 (이 PC에 PowerPoint가 없어 파일 안의 도형·글·표·차트를 그대로 읽어 그린 근사 그림. 글꼴·줄바꿈이 실제와 조금 다를 수 있고 모든 결과물에 똑같이 적용됨)
명령 실행이나 파일 수정은 하지 말고 그림만 보고 평가해.

[채점] 각 결과물을 항목마다 1~5점(정수)으로:
- content: 내용의 질 (사실이 맞는가, 구체적인가, 실제 자료·예시·수치가 있는가, 깊이와 완결성, 채우지 않은 빈칸이 없는가)
- design: 디자인 (색·구성·시각적 위계·정돈된 느낌, 알맞은 표현 방식, 단조롭지 않음)
- readability: 가독성 (글자가 읽히는 크기인가, 대비, 겹침·잘림·빈 화면 없음, 정보량이 알맞은가)
- fit: 목적 적합성 (요청한 대상·용도·분량·형식에 맞고, 고치지 않고 바로 쓸 수 있는가)
그림에 안 보이는 것은 추측하지 말고 보이는 대로만 평가해. 결과물이 없거나 깨졌으면 네 항목 모두 1점. 마지막에 1위부터 4위까지 순위(동점 없이)를 매겨.
