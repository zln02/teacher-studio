## 3. 제작 순서와 검사기에서 바꿀 점

**분명한 요청의 기본 순서**는 `요청과 파일 형식 확인 → 가능한 도구 선택 → 필요한 내용 작성 → 제작 → 검사 → 전달`로 줄일 수 있습니다. 현재 `ask-first.md`는 분명하면 만들라고 하지만 입구 스킬은 「알아서」가 없는 게임·영상 요청을 콘티에서 멈춥니다. 콘티 확인은 사용자가 요청했거나 방향 선택이 결과를 크게 바꿀 때 쓰세요. 「알아서」는 취향 결정을 맡긴다는 뜻으로 처리하고, 외부 게시·전송 확인은 그 표현보다 먼저 적용해야 합니다. 두 번 고쳐도 도구가 맞지 않으면, 일반 모델 경로에서도 사용 가능한 검색·제작·검사 도구를 활용해 동일한 필수 기준으로 결과를 확인할 수 있어야 합니다. 현재 `bare`의 `no tools`는 이 경로를 약하게 만듭니다.
