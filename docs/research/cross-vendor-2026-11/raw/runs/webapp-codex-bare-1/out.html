곱의 법칙
선택이 여러 단계로 이어지고 앞에서 무엇을 골라도 다음 단계의 선택 수가 같으면, 단계별 경우의 수를 곱해요. 상의 3가지와 하의 2가지라면 3 × 2 = 6가지예요.
합의 법칙
두 종류의 경우가 서로 겹치지 않고 그중 하나만 고를 때, 종류별 경우의 수를 더해요. 버스 3개 노선 또는 지하철 2개 노선 중 하나를 고르면 3 + 2 = 5가지예요.
순서가 있는 경우
역할이나 자리가 다르면 같은 사람을 뽑아도 순서에 따라 다른 경우예요. 3명 중 회장과 부회장을 한 명씩 겸임 없이 뽑으면 3 × 2 = 6가지예요.
