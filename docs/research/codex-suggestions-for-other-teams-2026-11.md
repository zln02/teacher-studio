# 2026년 11월 Codex 검토 후속 제안

두 하네스 검토 중 다른 팀의 파일이나 통합 배포에 걸친 제안입니다. 이 작업에서는 아래 폴더와 배포 파일을 보존했습니다.

- **슬라이드 팀**은 파일 생성, 파일 구조 검사, 실제 PowerPoint 열기와 화면 확인을 따로 기록해 주세요. 웹 슬라이드가 맞더라도 PPT 파일을 만들지 못하면 PPT 완료로 표시하지 않습니다. 문서 위치로만 그린 미리보기는 근사 화면이라고 표시하고, 실제 그림에서 줄 넘침과 잘린 글자를 다시 봅니다. 공통 무대와 문법 검사 사본도 다음 통합 때 동기화해 주세요.
- **문서 팀**은 Codex에서 활성화된 문서 도구 목록을 먼저 사용해 주세요. 폴더 이름만으로 공식 도구나 실행 가능 여부를 판단하는 대신 앱에서 실제 파일 열기·수정·인쇄를 확인합니다. 학교명·행사일·금액에 근거가 없으면 「바꿔 넣을 곳」에 남깁니다. 파일 검사 실패나 일부 미확인은 완료 표시와 분리합니다.
- **연수 자료 팀**은 같은 모델에 같은 요청을 주고 권한·도구·제한 시간을 맞춘 뒤, 교사 스튜디오를 적용한 결과와 일반 결과를 짝지어 비교해 주세요. 새 사례를 여러 번 실행하고 첫 답변의 완성 파일과 후속 수정본을 따로 보관합니다. 파일 열림, 작동, 개인정보 여부와 함께 교사 평가 결과, 질문 횟수, 한쪽만 실패한 건수도 남깁니다.
- **통합 배포 담당**은 공통 사본을 전부 맞춘 뒤 ZIP을 다시 만들고 `python3 tools/sync_shared.py --check`를 통과시켜 주세요. Windows에서는 `py`를 사용합니다. 출시 묶음은 설치 후 빈 작업 폴더에서 평소 말로 한 요청과 직접 스킬을 고른 요청을 나눠 시험합니다. 선택 예측 점수와 실제 파일 완성 여부는 따로 기록합니다.
