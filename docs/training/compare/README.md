## 결론 먼저 (v2)

- **v1에서 지적한 약점은 대부분 고쳐졌다.** 게임은 제목 가림·보기 글자 잘림이 사라지고 15문항이 모두 맞았다. 성적 보고서의 한 줄 결론은 이제 반 전체(3과목) 기준이고, 엑셀에 차트 4개가 들어갔다. 법 질문은 742초에서 55초로 줄었다.
- **가장 큰 개선은 학부모 발표자료다.** 선생님이 바로 고칠 수 있는 `.pptx`(8장, 발표자 메모 포함)가 나왔다. 일반 AI와 같은 형식이 됐고 색 디자인은 더 낫다. 다만 `[대괄호]` 빈칸 25곳과 `20XX` 2곳이 남아 있다(일반 AI도 같은 문제).
- **아직 일반 AI가 낫거나 비슷한 곳**
  - 속도와 비용: 게임 637초 대 310초, 학부모 $0.64 대 $0.44. 법 질문 비용도 $0.27 대 $0.06이다. (일반 AI 게임은 이번에 다시 돌리지 않았다. v1 값.)
  - 기능 수: 일반 AI 게임은 반사·색 합성 미니게임까지 있었다.
  - 게임은 이번에도 **끝났다는 최종 답변이 없다**. "서브 에이전트가 만드는 중"이라는 문장만 남기고 `-p`가 끝났지만 파일은 완성돼 있었다.
  - 법 질문은 이번에도 국가법령정보센터 조문 원문을 열지 못해 2차 자료 링크로 답했다(그 사실은 솔직히 표시함).
- **학부모 `.pptx`는 이번에도 AI가 직접 화면으로 확인하지 못했다.** 이 PC에 LibreOffice가 없다. 파일이 스스로 "글자가 넘칠 수 있으니 PowerPoint에서 확인해 달라"고 알렸다.

## v2 방법과 v1과 달라진 점

- v1과 같은 방법이다. `CLAUDE_CONFIG_DIR`을 로그인 정보와 `teacher-*` 7개 스킬(현재 `~/.claude/skills`)만 있는 폴더로 지정해 `claude -p --model sonnet --permission-mode bypassPermissions --output-format json`으로 실행했고, 사례마다 따로 빈 임시 폴더를 썼다. 일반 AI는 다시 돌리지 않았다.
- **요청 문장이 하나 다르다.** 학부모는 「학부모 총회 발표자료 **PPT로** 만들어 줘 (8장 정도)」로 바꿔 `.pptx` 내보내기 길을 시험했다. v1은 「발표자료 만들어 줘」였다. 따라서 학부모 줄의 v1과 v2는 같은 요청이 아니다. 게임·성적에는 「알아서 끝까지 만들어 줘」와 저장 문구를 붙였고, 법은 질문 그대로 보냈다.
- 4개를 동시에 돌렸다(v1은 8개). 제한 시간은 1500초였다(v1은 900초).
- **성적 분석은 두 번 돌렸다.** 첫 실행은 결과 파일이 만들어졌지만 `_result.json`(비용·토큰)이 폴더에서 사라져(AI가 임시 파일을 정리한 것으로 보임) 측정이 안 됐다. 그래서 같은 조건으로 한 번 더 돌려 표에는 두 번째 실행(71초)을 썼다. 첫 실행 파일은 보관하지 않았다.
- 게임 비용은 메인 세션 값이다. 서브 에이전트(게임 제작)가 별도로 쓴 비용이 포함됐는지는 확인하지 못했다.
- **스크린샷:** `<사례>-harness-v2.png`(1600x900). 게임·성적은 실제 HTML을 Chrome(`--mute-audio`)으로 찍었다(`-key`는 시작 후/아래로 스크롤한 화면).
  - 학부모 `.pptx`는 이 PC에서 슬라이드를 그릴 도구가 없어서, 파일 안의 도형 위치·색·글자·정렬을 읽어 HTML로 **근사 재현**했다. `parents-harness-v2.png`는 1·3·4·6쪽 4장, `parents-harness-v2-all.png`는 8장 전체다. 글꼴과 줄바꿈, 글자 넘침은 실제 PowerPoint와 다를 수 있다.
  - 법 질문은 v1과 같은 카드 양식에 답변 글을 그렸다.
- 원본: `raw/v2/<사례>/`(결과 파일, `_result.json`, `_secs.txt`), 실행·촬영 스크립트 `raw/v2/run2.sh`, `raw/v2/shotv2.py`.
- 한 번씩만 실행했다. 점수와 "손봐야 할 곳 수"는 제가 직접 센 주관 값이고 통계적 결론이 아니다. 게임 15문항은 문제 파일(`spec.json`)에서 표본과 전반사 문항까지 정답을 확인했다.

# v1 (처음 비교)

## 결론 먼저

- **겉모습(디자인)과 교실에서 바로 쓰는 완성도는 교사 스튜디오가 앞섰다.** 게임(TV용 큰 화면, 팀 모드)과 학부모 총회 발표(칠판풍 통일 디자인)에서 차이가 뚜렷했다.
- **법 질문은 "근거를 보여 주고 확인 못 한 것을 솔직히 말하는 점"에서 교사 스튜디오가 앞섰다.** 일반 AI는 출처·확인일 없이 조문 번호를 기억에서 꺼내 답했다. 다만 이번 실행에서 교사 스튜디오도 국가법령정보센터 조문 원문은 열지 못했다(접속 차단). 그래서 "원문 확인 완료"는 아니고 "확인 못 한 것을 표시한 답"이다.
- **일반 AI가 이긴 곳도 있다.**
  - 성적 분석: 석차, 주의 대상 학생, 과목 간 상관을 더 깊게 분석했고 엑셀 차트 2개를 넣었다.
  - 학부모 발표: 선생님이 바로 고칠 수 있는 `.pptx` 파일을 만들었다. 교사 스튜디오 결과는 브라우저용 HTML이다.
  - 속도와 비용: 법 질문은 59초 / $0.06 대 742초 / $0.23이었다. 게임은 반대로 교사 스튜디오가 약 23분에 걸렸다.
  - 게임 기능: 일반 AI가 15문제 퀴즈 외에 반사 챌린지, 색 합성 미니게임까지 만들어 기능은 더 많았다.
- **교사 스튜디오의 약점(이번 실행에서 확인한 것)**
  - 게임이 15분 상한 안에 끝나지 않았다. 파일은 만들었지만 최종 답변이 없다.
  - 게임 화면에서 제목 글자가 장식 도형에 가려지고, 보기 글자가 말풍선 밖으로 잘렸다.
  - 성적 보고서의 "한 줄 결론"이 국어 한 과목 이야기인데 반 전체 결론처럼 보인다.
- **학생 정보 처리:** 교사 스튜디오는 이름을 가명으로 바꿔 분석하고 "자료는 어디로도 보내지 않았다"고 알려 줬다. 일반 AI는 학생별 순위와 주의 대상 명단을 그대로 출력하고 개인정보 안내는 없었다. 이번 자료는 가짜 이름(학생01~25)이라 실제 문제는 없었다.

## 방법

- 모델은 `claude -p --model sonnet`으로 양쪽 동일. 모두 비대화형이고 `--permission-mode bypassPermissions --output-format json`을 썼다. 각 실행은 자기 전용 빈 임시 폴더에서 돌렸고 한 번에 8개를 병렬로 실행했다(제한 시간 900초).
- **일반 AI (bare):** `CLAUDE_CONFIG_DIR`을 로그인 정보(`.credentials.json`)만 있는 빈 폴더로 지정했다. 사용자 CLAUDE.md, 훅, 플러그인, 교사 스튜디오 스킬이 모두 없다.
  - 확인: "쓸 수 있는 스킬을 나열해"라고 물으니 계정 기본 스킬(`pdf`, `xlsx`, `pptx`, `docs` 등)만 나오고 `teacher-*`는 없었다. 그래서 일반 AI가 `.pptx`와 `.xlsx`를 만든 것은 이 기본 스킬 덕분일 수 있다.
- **교사 스튜디오 (harness):** 위와 같은 빈 설정 폴더에 `~/.claude/skills`의 7개 스킬(`teacher-studio`, `-game`, `-slides`, `-data`, `-law`, `-motion`, `-class-tools`)을 복사했다. 확인: 같은 질문에 `teacher-*` 7개가 나왔다. 실행 시점의 복사본이며 다른 작업자가 스킬을 고치는 중이었다.
- **요청 문장:** 아래 문장 뒤에 `알아서 끝까지 만들어 줘.`를 붙였고, 파일을 만드는 3개 사례에는 `결과 파일은 지금 폴더에 저장해 줘.`도 붙였다. 두 조건에 똑같이 붙였다.
  - 게임: 「중2 과학 빛 단원 복습 게임 만들어 줘」
  - 학부모: 「학부모 총회 발표자료 만들어 줘 (8장 정도)」
  - 성적: 「우리 반 성적 엑셀 분석해 줘」. 폴더에 가짜 `성적.csv`(학생01~25, 국어·수학·과학, 난수 점수)를 두었다. 실제 자료는 쓰지 않았다.
- **법 질문은 한 번 다시 돌렸다(프로토콜 실수 수정).** 처음에는 질문 뒤에 `알아서 끝까지 만들어 줘.`를 붙였는데, 일반 AI가 질문에 답하지 않고 가정통신문 양식을 만들어 버렸다. 질문에는 맞지 않는 문구였으므로, 법 질문만 문구 없이 원문 그대로(「가정통신문에 인터넷에서 찾은 캐릭터 그림 써도 돼?」) 다시 돌려 표와 이미지에 사용했다. 처음 결과는 `raw/law-with-suffix/`에 있다. 총 실행은 10회(법 2회 추가).
- **스크린샷:** Playwright + 시스템 Chrome(`--mute-audio`), 1600x900. 게임은 시작 화면과 "시작" 클릭 후 문제 화면, 교사 스튜디오 발표는 1쪽과 3쪽(보기마다 키를 눌러 나타나는 방식이라 6번 눌러 모두 표시)을 찍었다.
  - 일반 AI의 `.pptx`는 이 PC에 LibreOffice·PowerPoint 자동 렌더가 없어서, 파일의 도형 위치·색·글자를 읽어 HTML로 **근사 재현**했다. 실제 PowerPoint 화면과 약간 다를 수 있다.
  - 성적 사례의 일반 AI `.xlsx`는 시트 값을 표로 재현했고 차트는 화면에 넣지 못했다. 그래서 디자인 점수가 낮게 나왔을 수 있다.
  - 법 질문은 두 답변 텍스트를 같은 카드 양식(`raw/law/*/_card.html`)으로 그렸다. 카드 높이만 글 길이에 따라 다르다.
- **원본:** `raw/<사례>/{bare,harness}/`에 결과 파일, `_result.json`(비용·토큰·답변), `_secs.txt`(걸린 초). 실행·촬영 스크립트는 `raw/`에 있다.

## 주의할 점 (한계)

- **한 번씩만 실행했다.** 같은 요청도 매번 결과가 다르다. 점수는 제가 직접 본 주관 점수이고 통계적 결론이 아니다.
- 교사 스튜디오는 원래 중간에 선생님께 확인을 받는 방식인데, 이번에는 "알아서 끝까지"로 그 단계를 건너뛰게 했다. 실제 사용에서는 확인 질문 때문에 더 오래 걸리지만 선생님 취향에 더 맞춰질 수 있다. 이 효과는 이번 비교에 반영되지 않았다.
- 8개를 동시에 돌려서 **시간·비용에 서로 영향**이 있을 수 있다. 특히 게임 교사 스튜디오(1397초)와 법 교사 스튜디오(742초)는 병렬 부하나 법령 사이트 접속 지연의 영향이 있을 수 있다.
- 게임 교사 스튜디오 실행은 제한 시간에 걸려 JSON 결과가 비었다. 비용·토큰은 알 수 없고, 게임 파일은 그 전에 완성되어 있었다(작성 시각 약 11분째).
- 법 질문의 "정확성"은 제가 법 원문과 대조한 것이 아니다. 방향의 타당성과 확인 표시의 솔직함만 평가했다.
- 일반 AI 법 답변에 `Canva·미리캔버스 무료 요소` 안내가 있는데 약관 확인은 하지 않았다.
- 학부모 발표는 두 쪽 모두 글 위주이고, 실제 총회 내용(학교 행사 일정 등)은 확인 불가한 일반 내용이다.
