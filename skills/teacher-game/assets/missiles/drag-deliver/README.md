# 끌어서 보내기 (drag-deliver)

## 언제 쓰나
- 「짝 맞추기」「뜻 맞히기」「분류하기」를 **손으로 끌어서** 하고 싶을 때. 물건(단어·문제·물질)을 알맞은 곳(집·세포 방·분리수거 통)으로 보낸다. 끌기 대신 **눌러서 골라도** 된다(물건을 누르고 → 보낼 곳 누르기, 또는 보낼 곳을 바로 누르기).
- 칠판 팀전(2~4팀 차례제)과 태블릿 개인전 모두. 2번 기회, 정답마다 세계 그림이 자라고, 마지막에 큰 장면 → 결과.

## 선생님 말 예시
1. 「영어 단어 12개, 뜻 맞히기 게임 칠판으로 4팀 대결」 → `post-office`
2. 「세포 단원 10문제, 애들 태블릿으로 혼자 풀게 귀엽게」 → `cell-feed`
3. 「순물질·혼합물 분류 게임, 공장 느낌으로 2팀」 → `recycle` (분류형: 통이 고정)

## content.json 형식
```json
{"title": "…", "subtitle": "…", "teams": 0, "timer": 0,
 "world": {"instruction": "…", "itemTag": "…"},
 "items": [{"q": "보낼 것", "a": "정답 도착지", "wrong": ["오답1", "오답2"], "exp": "해설 한 줄", "say": "읽어 줄 말"}]}
```
- `q` 보낼 것(단어·문제 문장·물질 이름) · `a` 정답 도착지 이름 — **필수**
- `wrong` 오답 도착지(선택). 없으면 다른 문제의 `a`에서 자동으로 뽑는다.
- `exp` 정답 뒤 해설(선택) · `say` 🔊 버튼으로 읽어 줄 말(선택)
- **분류형 자동 판정**: `wrong`이 하나도 없고 `a` 종류가 2~4개면 통이 고정(매번 같은 자리)된다. `world.bins`로 순서를 정할 수 있다(모든 `a`가 들어 있어야 적용).
- 문제 수 5~20개 권장. 도착지는 문제마다 2~4개(`world.dests`, 기본 4).

### world 키 (선생님이 바꿀 만한 것)
| 키 | 뜻 |
|---|---|
| `titleTag` `how`(줄 배열) `startLabel` | 제목 화면 작은 글·설명·시작 버튼 |
| `instruction` `guide` `tapHint` `retryLine` | 위쪽 안내 띠 문장 (첫 문제 따라 하기·누르기·다시 하기) |
| `itemTag` `bonusTag` `bonusBadge` | 보낼 물건 위 꼬리표, 황금(2배) 문제 |
| `goodBadge` `secondBadge` `wrongBadge` `revealBadge` | 정답·두 번째 정답·오답·정답 보기 배지 |
| `pairJoin` / `answerPrefix` | 해설 카드 첫 줄: `"apple = 사과"`(pairJoin) 또는 `"정답: 세포"`(pairJoin을 null로) |
| `afterGood` `afterBad` | `exp`가 없을 때 해설 카드 둘째 줄 |
| `nextLabel` `lastLabel` | 다음 버튼 / 마지막 버튼 |
| `dests` `tries` `shuffle` | 도착지 수(2~4) · 기회(기본 2, 도착지 2개면 1) · 문제 섞기(false면 순서대로) |
| `speak` `lang` `rate` | true면 `q`를 자동으로 읽어 줌(영어 en-US). **영어가 아니면 `speak:false`** |
| `bins` `destHints` | 분류형 통 순서, 통 아래 작은 설명 `{"순물질":"한 가지 물질"}` |
| `levels` `towerTitle` `levelBadge` `talk` | (cell-feed) 탑 층 이름 5개, 몽글이 말풍선 `{start,next,almost,good,wrong,grow,end}` |
| `growLabel` `rain` | 성장 표시 아이콘, 정답 때 내리는 이모지 |
| `finaleLine` `finaleLineSome` `finaleBadge` `endAll` `endSome` `countLine` `unit` | 마지막 장면·결과 제목(`{n}`,`{total}` 자리 표시) |
- 그 밖의 게임 키: `teams`(0/2~4) `teamChoice` `timer`(초, 0=없음) `bonusEvery`(기본 4, 0=끔) `calm` `music`.

## 스킨
- `post-office` 달밤 우체국 마을 — 우체부 고양이, 지붕 4종 집, 정답마다 마을 집 불이 켜지고 마지막엔 단어 축제 불꽃. 영어 듣기(🔊). 칠판 4팀·25초.
- `cell-feed` 몸속 마을 먹이 주기 — 입 벌리는 세포 방 4종, 먹이 젤리 카드, 탑이 한 층씩 차면 몽글이가 세포→…→토끼로 진화. 태블릿 개인·타이머 없음.
- `recycle` 분리수거 로봇 공장 — 컨베이어 벨트로 들어오는 캡슐, 뚜껑 열리는 분리수거 통, 정답마다 로봇 배터리 충전, 마지막엔 로봇 로켓 출동. 칠판 2팀·30초.

## 크기·사용 환경
- 1920×1080 무대(엔진이 화면에 맞춤). 칠판: 보낼 물건 글자 76~96px, 도착지 글자 56~62px, 버튼 110px. 태블릿(cell-feed): 문제 54px, 도착지 50px, 보조 글 32px 이상.
- 글자가 길면 자동으로 줄이고 줄바꿈한다(도착지 이름은 한 줄 6~7글자 정도까지가 보기 좋다).
- 선생님 메뉴(⚙): 정답 보기 = 정답 집이 열림, 다음으로 = 안 푼 문제는 건너뜀. Space = 다음.

## 확인된 것 (2026-11-18)
- 세 스킨 모두 `fire.py` PASS, 헤드리스 크롬 1280×720으로 결과 화면까지 플레이: 끌기 정답·오답 후 재시도·누르기 선택·⚙ 정답 보기·⚙ 다음으로·시간 초과·황금 문제·틀린 문제만 다시·처음으로. 페이지 오류 0.
- 팀 0/2/3/4, 차분 모드(calm), 다른 과목 내용(속담 3지선다 긴 보기, 대륙 4통 분류)으로도 확인.
- 한계: 4팀일 때 엔진 선생님 메뉴 패널이 작은 화면에서 위아래로 넘침(엔진 공통). 보낼 물건이 아주 긴 문장(40자 이상)이면 글자가 작아진다.
