# 0005. 법률 안내: 법 조문을 저장하지 않고 공식 출처를 실시간 조회한다

- 상태: Accepted (2026-11-18)

## 배경
선생님은 「이 캐릭터 넣어도 돼요?」「학생 이름 넣어도 돼요?」「AI로 생기부 써도 돼요?」처럼 자주 묻는다. 개인정보 보호법, 저작권법, 인공지능 기본법, 교육부 지침은 계속 바뀌고, 저장소에 적어 둔 결론은 곧 낡은 정보가 된다. 틀린 법률 안내는 없는 것보다 해롭다.

## 결정
`skills/teacher-law`는 **법 내용을 담지 않고 「찾는 순서 + 믿을 출처 + 고정 답 카드」만** 담는다.
- 매번 국가법령정보센터 등 **공식 출처 원문**을 열어 조항·시행일·확인한 날을 적는다(`references/sources.md`). seed 목록(조항 이름·번호)도 「매번 원문 재확인」으로 표시한다.
- 답은 **고정 카드**: 한 줄 결론(단정 금지) / 이유 / 근거(법령명·조항·시행일·링크·확인일) / 선생님 책임 문구.
- 확인하지 못한 것은 「확인 필요」. 작업을 막지 않고, 법률 자문이 아님을 항상 밝힌다. **책임은 선생님께** 있다.
- **웹 검색이 없는 환경**에서는 최신 확인이 불가능하다고 말하고 **공식 링크만** 안내하며 결론은 말하지 않는다.

## 검토한 대안
- **법 조문 요약을 저장소에 내장**: 오래되면 오답. 유지 비용 큼. 기각.
- **RAG(법령 벡터 DB)**: 색인 갱신·호스팅이 필요하고, 갱신이 늦으면 같은 문제. 정적 저장소에 맞지 않음. 기각.
- **법령 Open API 연동**: 가입과 OC 값(신청 키)이 필요한 것으로 보이며, 키를 요구하는 클라이언트는 만들지 않는다. 학교·교육청 단위 키가 생길 때 재검토(`sources.md` 3절, 일부는 공식 확인 못 함).
- **법적 문제가 있으면 제작 거부**: 선생님의 정당한 사용까지 막음. 기각 — 알리되 막지 않는다.

## 결과
- 장점: 저장소가 낡아도 답은 최신 원문에 근거. 근거 없는 단정 방지. 다른 스킬이 학생 정보·남의 저작물·공개 공유·생기부가 걸린 요청에서 이 절차를 호출해 한 줄을 덧붙인다.
- 단점: 검색 도구가 없거나 Codex가 `cached` 검색이면 최신성이 떨어진다(환경별 안내는 `SKILL.md`). 응답이 느리고 답 품질이 검색 능력에 의존한다. 상표·학교 규정은 seed가 없어 「확인 필요」 상태다.
