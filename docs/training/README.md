# 교사 연수 자료: AI가 중간에 포기한 진짜 이유 (60분)

대상: 일상 업무에 AI를 써 보려는 초·중·고 선생님. 영상 편집 등을 AI로 해 보다 중간에 포기한 분이 많아요.
핵심 메시지: **AI는 이미 실력이 좋아요. 지쳐 떨어진 건 AI에게 무기(도구·레시피·재료·검수)가 없었기 때문이에요. 잘 쓰는 사람은 주방을 갖춰 줘요.**
선생님은 내부 용어를 몰라도 돼요. 쓰는 말은 요리사(AI)·주문서(요청)·재료비(시간·비용)·가짜 메뉴(엉터리 답) 네 개뿐입니다.

## 구성 (60분)
| 시간 | 내용 |
|---|---|
| 0–10 | 공감: 영상 편집하다 포기한 이야기, 맨 AI가 헤매는 녹화 보기 |
| 10–20 | 왜 포기했을까: 빈 주방의 요리사, 잘 쓰는 사람은 주방을 갖춘다 |
| 20–35 | 같은 일, 무기를 쥐여 줬을 때 (시연 4개 비교) |
| 35–50 | 모둠 실습: 진짜 일 하나를 갖춘 AI에게 (주문 팁 카드 1장) |
| 50–57 | 꼭 지킬 3가지 (알레르기·원산지·상차림 책임) |
| 57–60 | 「그래서 제가 만들었습니다 😎」 + 설치 QR + GitHub |

슬라이드 만들기 (저장소 루트에서, 점검기 PASS 확인함):
`python3 skills/teacher-slides/scripts/build_stage.py --missile lesson-deck --skin notebook-pastel --content docs/training/deck.json --out deck.html`
→ `python3 skills/teacher-slides/scripts/check_page.py deck.html` → 크롬에서 열고 F로 전체 화면. N = 발표자 메모.

| 메뉴판의 한글 문서·점수 정리·음성·PPT 파일 | 각 도구 | 준비 중 |

## 준비 체크리스트
연수 전날까지
- [ ] 모둠마다 공용 PC 1대 (인터넷, 크롬). 모둠 수 [입력]
- [ ] AI 서비스 계정: 선생님 본인 계정(만 18세 이상), 모둠 PC마다 로그인 확인. 학생 계정 금지
- [ ] 학교망에서 AI 서비스·GitHub 접속 차단 여부 확인 (안 되면 핫스팟·개인 노트북)
- [ ] 교사 스튜디오 zip을 AI 서비스(Claude 등)에 **미리 업로드**해 두기 (모둠 PC도)
- [ ] **맨 AI가 영상 편집을 시도하다 헤매는 장면 녹화**(1~2분), 같은 일을 갖춘 AI로 한 결과 (슬라이드 4번)
- [ ] 시연 ①~④를 맨 AI/갖춘 AI로 한 번씩 돌려 시간·주고받은 횟수·결과 기록, 백업 파일(결과, 캡처, PDF) 저장
- [ ] 슬라이드 「[시연 후 입력]」 칸을 실제 값으로 채우기 (재지 않은 값은 비우기)
- [ ] 설치 QR 만들기(주소: https://github.com/zln02/teacher-studio), 큰 종이 출력본
- [ ] 메뉴판·포켓 카드 인쇄 (모둠 수 + 여유분)
- [ ] 스톱워치/타이머, 슬라이드 리모컨
연수 직전
- [ ] 슬라이드를 끝까지 넘겨 보기, 백업 파일 위치 확인

## 이 연수의 약속
- 학생 이름·사진·성적은 화면에도, 입력에도 넣지 않아요.
- 측정하지 않은 숫자는 말하지 않고, 없는 기능을 되는 것처럼 보이지 않아요.
- 도구가 이기지 못한 부분도 그대로 보여 줘요.
- 교사 스튜디오 소개는 마지막 3분, 겸손하게.
