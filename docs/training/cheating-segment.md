## 시연: 찍고 → 보내고 → 풀고 → 받기 (약 5분, 발표자 혼자)

슬라이드: [deck-v2.html](deck-v2.html) 34~36장 (`#34`로 바로 가요). 이 구간도 **시간이 남을 때만** 해요. 참여자는 따라 하지 않고 보기만 해요.

- **목적:** 「찍고 → 보내고 → 풀고 → 받기」 한 바퀴가 얼마나 빠른지 몸으로 느끼고, 감독이 어느 단계에서 끊을 수 있는지로 넘어가기.
- **준비물:** 평소 쓰는 휴대폰 1대, 발표용 노트북(AI 채팅 창을 미리 열어 둠), 리허설 때 찍어 둔 화면 4장(아래 「인터넷이 안 될 때」).
- **안전선:** 사진을 어떻게 옮기는지, 어떤 프로그램·서비스를 썼는지, 휴대폰 설정은 말하지도 화면에 띄우지도 않아요. 화면 공유는 슬라이드만, 노트북 AI 창은 답이 나온 순간만 잠깐.
- **시계:** 34장 가운데 큰 시계. **T** 시작·멈춤, **L** 단계 찍기(또는 칸을 눌러요), **R** 처음으로. 35장 오른쪽 아래 작은 시계는 같은 시계라서 장을 넘겨도 계속 돌아요.

### 순서
1. **34장** 「말로만 들으면 감이 잘 안 오시죠. 제가 직접 한 번 해 볼게요. 여러분은 보기만 하시면 돼요. 얼마나 걸리는지 이 시계로 잴게요.」
2. **35장**으로 넘겨 예시 문항을 띄워요. 「연필과 공책 가격 문제예요. 중2 수학, 제가 직접 만든 문제예요.」
3. **T**를 누르고 휴대폰으로 화면을 찍어요. 「지금 시계 켰어요. 찍을게요.」 (← 키로 34장에 돌아가 큰 시계를 보여 줘도 돼요. 시계는 계속 돌아요.)
4. 사진이 노트북에 닿으면 **L** (보내기 끝). 「노트북에 왔어요.」
5. AI 창에 사진을 넣고 답이 나오면 **L** (풀기 끝). 「AI가 풀었어요. ③ 600원, 맞았어요.」
6. 답을 휴대폰으로 받으면 **T**로 멈춰요. 「휴대폰에 답이 왔어요. 다 해서 ○○초예요. 시험 한 문제 푸는 시간보다 훨씬 짧죠.」 (찍기 단계는 3에서 바로 **L** 한 번.)
7. **36장** 「방금 본 네 단계 중 하나만 끊겨도 답은 돌아오지 않아요. 그래서 감독은 단계마다 살필 게 있어요.」 → 표를 한 줄씩. 마지막 줄: 「평소 AI로 공부하는 건 괜찮다, 시험 중엔 여기부터 부정행위다, 이 선을 미리 알려 주세요. 의심은 증거가 아니에요.」

정답 메모: 연필 x원, 공책 y원 → 3x + 2y = 3400, x + 3y = 3000 → x = 600, y = 800. **③ 600원.** 화면에는 정답을 띄우지 않아요.

### 인터넷이 안 될 때 (미리 찍어 둔 화면으로)
리허설 때 같은 순서로 한 번 해 보고, 화면 4장과 그때 잰 시간을 휴대폰 사진첩·노트북 폴더에 따로 둬요.
1. 휴대폰 카메라가 35장 문제를 비추는 화면
2. 노트북에 사진이 도착한 화면 (프로그램 이름·주소·설정이 보이면 잘라 내요)
3. AI가 답 ③ 600원을 낸 화면
4. 휴대폰에 답이 도착한 화면 (같은 방법으로 잘라 내요)

말할 것: 「오늘 여기 인터넷이 안 돼서, 어제 똑같이 해 본 화면으로 보여 드릴게요. 그때 잰 시간은 ○○초였어요.」 시계는 R로 비워 두고, 리허설 기록 시간만 말로 전해요. 화면 4장은 덱이나 공개 사이트에 올리지 않아요.
