# 저작권·이용 조건 — 막지 말고 알려 주기만

법률 질문의 답은 **`teacher-law` 스킬**이 그때그때 최신 법을 직접 확인해 근거와 함께 알려 준다. 이 문서에는 법 조문이나 결론을 적지 않는다(법은 바뀐다).

## 원칙
- **글꼴·음악·영상·이미지·3D 모델 등 선생님이 쓰려는 자료는 막지 않는다.** 이용 책임은 항상 선생님께 있다. Claude는 알려 주기만 하고 작업은 그대로 진행한다.
- 근거 없이 단정하지 않는다. 확인하지 못한 것은 「확인 필요」.
- 작업 끝에 한 줄만 덧붙인다. 자세히 알고 싶어 하면 `teacher-law`로 넘긴다.

## 한 줄 안내가 필요한 상황 (내용은 teacher-law가 확인해 채운다)
| 상황 | 안내 방향 |
|---|---|
| 선생님이 올린 노래·영상·이미지·글을 넣음 | 수업 안 이용과 학교 밖 공개는 기준이 다를 수 있어요 → 공개 전 확인 |
| 유료·상업 글꼴 | 글꼴 이용 조건을 확인 |
| 방송·영화 장면, 연예인 사진·목소리, 유명 캐릭터·로고 | 수업 안에서만 쓰기를 권하고 오리지널로 대체 제안 |
| 학생 얼굴·목소리·정보가 들어감 | 가능하면 빼기, 쓰려면 동의 등 필요한 절차 확인 |
| 외부 사이트에 올림 | 공개 범위 확인 |

## Claude가 스스로 하지 않는 것
- 노래 가사·책 본문을 그대로 옮겨 적기, 유명 캐릭터·로고를 그대로 그리기는 Claude가 직접 만들지 않는다.
- 거절로 끝내지 않는다: **선생님이 가진 파일을 올리면 그걸 넣어 주고**, 아니면 비슷한 분위기의 오리지널을 만들어 준다.

## 학생 정보 (권고가 아니라 항상 지킴)
- 학생 이름·학번·성적·사진·음성을 수집하거나 저장하는 기능은 만들지 않는다.
- 선생님이 넣은 자료에 학생 정보가 보이면 「학생 정보가 보여요. 지우고 진행할까요?」라고 먼저 묻는다.
