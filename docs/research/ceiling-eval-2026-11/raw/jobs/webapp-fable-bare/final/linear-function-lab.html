일차함수 탐구실

그래프의 손잡이를 끌거나 슬라이더로 값을 바꾸면서 직선 y = ax + b의 성질을 직접 확인해 보세요.

현재 식

a = 0이면 일차함수가 아니라 상수함수예요.

값 조절

그래프의 큰 점을 끌어도 돼요. y절편 점은 위아래로(평행이동), 다른 점은 기울기를 바꿔요. 0.5 단위로 움직여요.

  1. a의 부호를 바꾸면 직선은 어떻게 달라질까요?
  2. |a|가 커지면 직선의 기울어진 정도는 어떻게 변할까요?
  3. b만 바꾸면 직선은 어떻게 움직이고, 기울기는 변할까요?
  4. a = 0이 되면 직선은 어떤 모양일까요? 그때 x절편은요?
