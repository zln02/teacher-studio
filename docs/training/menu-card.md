# 메뉴판 (모둠 책상용 · A4 한 장)

꿀팁 1~6을 적용해, 지금 하고 있는 진짜 일 하나를 AI에게 한 줄로 주문해 보세요.
누·어·느·재(누구에게 · 어디에 · 어떤 느낌 · 어떤 재료)를 넣을수록 맛있어요. 학생 이름·사진·성적은 넣지 않아요.

| 메뉴 | 이렇게 말해 보세요 | 지금 |
|---|---|---|
| 🎮 수업 게임 | 「5학년 과학 태양계 퀴즈 게임, 수업 시작 5분, 모둠 대결로」 | 되는 것 |
| 🖥 발표 슬라이드 | 「학부모 설명회 슬라이드 8장, 따뜻하게」 | 되는 것 |
| ✨ 과목 소개 영상·시작 화면 | 「1학년 영어 과목 소개 영상, 뉴스처럼」「수업 시작 카운트다운, 오늘은 분수의 덧셈」 | 되는 것 |
| ⚖️ 「써도 돼요?」 질문 | 「학생 사진을 학급 홈페이지에 올려도 돼요?」 | 되는 것 (최신 법 안내) |
| 🎬 행사 사진 영상·편집 | 「운동회 사진으로 음악 넣은 영상 만들어 줘」 | **준비 중** (과목 소개 영상은 됨) |
| 📄 가정통신문·공문(한글 파일) | 「체험학습 안내 가정통신문을 한글 파일로」 | **준비 중** (초안 글은 일반 AI에서 받아 붙여 넣기) |
| 📊 설문·점수 정리 | 「설문 결과를 표로 정리하고 요약해 줘」 | **준비 중** (학생 정보는 지운 표만) |
| 🎙 안내 방송 음성 | 「점심시간 안내 방송을 사람 목소리로」 | **준비 중** (컴퓨터 기본 목소리 읽기만) |
| 📁 PPT 파일 | 「PPT 파일로 줘」 | **준비 중** (웹 슬라이드 + PDF 인쇄로 대신) |

## 주문서 한 줄 틀
「[누구에게] [어디에 쓸 건데] [어떤 느낌으로] [이 자료로] [무엇을] 만들어 줘」
예: 「5학년 · 수업 시작 5분 · 신나게 · 첨부한 학습지로 · 태양계 퀴즈 5개」

## 만든 뒤에
- 시식: 내용이 맞는지 눈으로 확인 (사실·숫자·출처)
- 간 맞추기: 「더 크게」「더 따뜻하게」「3번만 고쳐 줘」
- 공개 전: 남의 그림·글·음악이 있으면 확인
